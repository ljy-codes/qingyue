# Mac / Windows 功能对照（Windows v0.18.0 基线）

这份表按 Windows 0.1–0.18 的发布顺序维护，作为 Mac 后续 build 的验收清单。Windows 最新基线为 `origin/feat/windows-client@0869803`（`v0.18.0`）。状态只描述 Mac 当前实现，不把 Windows 的测试结果当作 Mac 已通过。

状态含义：**已对齐**表示 Mac 有可用行为和回归；**部分对齐**表示只有核心或近似行为；**待补齐**表示尚未提供；**平台适配**表示功能点相同但入口必须使用 macOS 原生控件。

## Mac 需要保留的平台适配

以下差异是平台实现，不算产品功能多出来：红黄绿窗口控制、AppKit 系统菜单、`⌘` 快捷键、Finder 文件面板、LaunchServices 文件关联、`~/Library/Application Support/LightReader` 数据目录和 Intel macOS 13+ 构建目标。它们不应被删除，否则会破坏 macOS 使用习惯。

Mac 不再保留与 Windows 产品层级冲突的旧版额外按钮；主题、标签、侧栏、工具栏、状态栏和菜单按 Windows 信息层级组织。Word/Excel 编辑、云同步、账号、WebView、远程图片下载也不属于任一平台当前范围。

## 后续执行顺序

每个阶段都要同时补纯核心测试、AppKit 流程测试、使用说明和本矩阵状态，再提升 Mac 构建号：

1. 0.11：工作区扫描、全局搜索、阅读清单。
2. 0.12：批注 UI、锚点修复、高亮、简报入口、暖纸外观。
3. 0.13：列表快捷编辑、嵌套容器、写作工具栏和分屏双向定位。
4. 0.10：Mermaid flowchart、GFM 链接和可选更新检查。
5. 0.4–0.8：书签进度、外部三选一面板、图片缓存/可见区调度/重试。

任何 Mac 发布前，必须重新检查本表中每个“部分对齐/待补齐”项，避免只移植最新 Windows 版本而漏掉早期能力。
