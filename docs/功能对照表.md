## 平台等价实现

以下差异属于平台实现方式，不是缺失的共同功能：

- 快捷键：Mac 使用 Command，Windows 使用 Ctrl；命令分组和可用操作保持一致。
- 菜单：Mac 使用系统菜单与窗口菜单，Windows 使用窗口菜单条；六组入口一致。
- 设置：Mac 使用独立设置窗口，Windows 也提供独立设置窗口。
- 文本组件：Mac 使用 AppKit/TextKit，Windows 使用 WPF TextBox/FlowDocument。
- 文件权限：Mac 使用 POSIX ACL/xattr，Windows 使用 ACL、只读属性、重解析点和文件占用语义。
- 文件定位：Mac 使用 Finder，Windows 使用资源管理器。
- 剪贴板：两端分别生成平台原生富文本载荷，目标软件粘贴需分别人工验收。
- 安装：Mac 使用 App 包、代码签名和公证，Windows 使用 NSIS、HKLM 卸载登记和 Authenticode。
