# 轻阅 Mac 0.4.0 方案与验收

目标版本：**0.4.0 · Mac 构建 14**。目标平台为 macOS 13+；默认交付 universal（x86_64 + arm64），构建脚本保留单架构入口。

跨平台版本奇偶、功能矩阵和 GitHub 保留规则见 [跨平台版本与功能对齐规则](跨平台版本与功能对齐规则.md)。本轮只修改 Mac，不修改 Windows 实现。

## 本版本必须完成

1. 大文件搜索改为可取消、可报告进度的分块处理，保持匹配结果的 UTF-16 位置语义；普通字面搜索覆盖中文和 Emoji 大文本的性能回归。
2. 设置窗口在小屏和大字号下可用，预览区不再固定裁剪；应用外观设置后恢复文件/行列等状态信息。
3. 为主题派生色补充对比度回归，为设置控件补充自动化回归；消除可修复的 colorspace/剪贴板测试噪声。
4. 图标源图和构建流程支持高分辨率资源，并对关键尺寸做清晰度/存在性检查。
5. 统一版本、变更记录、使用说明、交付目录和验收文档，删除构建 10 的过时操作入口；记录 7 套现有主题与配色设计文档的对应关系。
6. 提供 Mac 构建与回归测试的 CI 模板及本地产物检查；构建产物必须通过 Info.plist、签名校验、校验和和 ZIP 内容检查。

## 外部条件

- Developer ID 签名、公证和 Apple Silicon 实机验收需要证书、Apple 账户和对应硬件；本机只能验证脚本路径、架构产物可生成性和 ad-hoc 包的完整性。
- Windows 客户端、Windows 安装器和 Windows GUI 验收不属于本版本范围。

## 明确延期

完整 CommonMark/GFM、完整 YAML 校验、Office 编辑、云同步、插件系统和多窗口属于独立产品项目；本版本只修复当前 Mac 交付中已经确认的性能、稳定性、设置、主题、图标和发布工程问题。工作区、阅读清单、批注继续保持独立窗口，除非验收中发现功能性阻塞。

## 验收门槛

- `bash 开发空间/scripts/test.sh` 全部通过，无未解释的失败；新增测试覆盖取消、进度、非 ASCII 大文本、设置状态恢复、主题对比度和图标资源。
- `bash 开发空间/scripts/build.sh` 生成 `交付产品/轻阅-macOS-0.4.0/轻阅.app`、SHA256 文件和 ZIP；默认产物必须含 x86_64 + arm64，`plutil`、`codesign --verify --deep --strict`、ZIP 内容检查全部通过。
- 交付版与安装版的版本号为 0.4.0 / 构建 14；README、CHANGELOG、使用说明和验收记录不得继续把构建 10 当作当前入口。
- 在当前硬件无法完成的 Apple Silicon、Developer ID、公证和真实剪贴板/多显示器验证，必须在验收记录中明确标注为外部验收项，而不是伪造通过。

## 发布前检查顺序

1. 运行完整单元/UI 测试并保存输出。
2. 构建 universal ad-hoc 交付包，检查版本、签名、校验和、ZIP 解包内容。
3. 如需定位单架构问题，再分别构建 x86_64 和 arm64 包并检查 Mach-O 架构；否则保留 universal 包作为客户交付物。
4. 审阅 Git diff、敏感路径、绝对路径和过时版本号，确认工作区只包含本版本改动。
5. 创建 0.4.0 发布提交和 tag，推送分支与 tag 到 GitHub。

当前 GitHub 凭据没有 workflow scope。CI 配置保存在 `docs/ci/macos.yml.template`，尚未启用；已有完整本地回归与产物检查结果。后续具备权限时复制到 `.github/workflows/macos.yml`，以实际 Actions 结果确认云端验收。
