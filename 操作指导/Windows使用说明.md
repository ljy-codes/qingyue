# 轻阅 Windows 使用说明

版本 0.6.0 · Windows 构建 1 · 2026-11-12。

## 安装与启动

双击 `轻阅-0.6.0-Windows构建1-x64-setup.exe`，首屏选好安装位置，直接点击“安装”。
可勾选创建桌面快捷方式；安装中显示进度、百分比与当前阶段，完成后可立即启动。
点击“浏览”选择父目录时会自动添加 `Qingyue` 子文件夹，例如选择 `D:\Program File`，
实际路径显示为 `D:\Program File\Qingyue`。若选中 `Qingyue`、`轻阅` 或已有轻阅安装文件夹，
则保留该路径，不重复添加子目录。也可直接在输入框中编辑完整安装路径。
仅为当前用户安装，默认位置为 `%LOCALAPPDATA%\Programs\Qingyue`，无需管理员权限。
安装包包含 .NET 10 桌面运行时，不需要另行安装 .NET。
面向 Windows 10 22H2 / Windows 11 x64；本轮在 Windows x64、系统 build 26300.9818 开发机验证，未逐一测试其他系统版本。
可将文件拖入窗口，或通过 `Qingyue.exe "D:\文档\示例.md"` 打开。

再次运行安装包可在原位置覆盖安装，设置与草稿保留；安装前须保存并关闭全部轻阅窗口。
更换位置请先卸载并保留用户信息，再重新安装。已有更高版本时拒绝降级。
请选择普通本地专用文件夹，安装器拒绝磁盘根目录、数据目录重叠与链接路径。
手动输入及静默安装 `/D=` 均按完整目标路径处理，不自动改写路径；不会直接安装进存放其他软件的公共目录。

也可使用 ZIP：解压整个 `轻阅-Windows-x64` 目录，双击 `Qingyue.exe`。
便携使用时不要只复制 EXE，同目录运行时文件需要一起保留。同一数据目录只允许一个程序实例。
本地构建尚未签名，无自动更新和文件关联。

## 卸载与用户信息

从 Windows“设置 → 应用 → 已安装的应用”找到“轻阅 · Qingyue”，或运行安装目录中的 `Uninstall.exe`。
卸载向导与安装器采用相同深色品牌设计，可选择：

- **保留用户信息（默认）**：移除程序、快捷方式与系统卸载登记，保留设置、最近记录、会话和恢复草稿。重新安装后可继续使用。
- **彻底卸载并清理用户信息**：同时删除 `%LOCALAPPDATA%\Qingyue` 中的上述信息。向导会再次确认，未保存的恢复草稿删除后无法恢复。

你在其他位置保存的文档不会被删除。安装目录中自行放入的其他文件会保留，因此有此类文件时安装文件夹可能仍存在。
链接路径、正在运行或被占用的程序文件会阻止操作；请关闭占用后重试。用户数据被占用导致清理失败时，向导会提示，可能已清理部分内容。
静默卸载 `/S` 始终保留用户信息，没有命令行彻底清理开关。
开发测试指定的 `QINGYUE_SUPPORT_DIRECTORY` 外部数据目录不属于安装器清理范围。

## 常用操作

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 新建 / 打开 / 保存 | Ctrl+N / Ctrl+O / Ctrl+S |
| 另存为 / 保存全部 | Ctrl+Shift+S / Ctrl+Alt+S |
| 阅读与编辑 | Ctrl+R |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 下一个 / 上一个匹配 | F3 / Shift+F3 |
| 跳转源文行 / 文档目录 | Ctrl+G / Ctrl+Shift+O |
| 返回跳转前阅读位置 | 顶部“返回位置”或 Alt+← |
| 侧栏 / 专注 | Ctrl+B / Ctrl+Shift+F |
| 切换标签 | Ctrl+Tab / Ctrl+Shift+Tab；Ctrl+1…8，Ctrl+9 到最后标签 |
| 关闭标签 / 重命名 | Ctrl+W / F2；双击标签也可改名 |
| 快速打开 | Ctrl+Shift+P |
| 字号 | Ctrl++ / Ctrl+- |
| 格式化 / 整理 TXT | 顶部按钮或 Ctrl+Alt+F |
| Markdown 分屏预览 / JSON 结构 | 编辑区顶部对应按钮 |
| 明暗、换行、行号、阅读版心 | 视图菜单 |

文本类型、保存编码和换行方式可在窗口右下方选择。选编码只决定下次保存；
若文件打开后乱码，请用“文件 → 按编码重新打开”，操作前先保存需要保留的编辑。
无 BOM 的 UTF-16 需要指定编码打开。首次检测在严格 UTF-8 失败后尝试 GB18030，无法可靠识别所有旧编码。

深色主题采用柔和石墨灰正文底色与暖灰文字，浅色主题可通过“视图 → 切换明暗主题”切换。
右下角三个下拉框会随主题调整文字、背景、悬停、选中与键盘焦点显示。

每个标签保留独立编辑器和撤销栈；格式化与全部替换可撤销。编辑器保留系统输入法默认行为，
当前不提供 Mac 版的整行 Tab/Shift+Tab 缩进和换行继承缩进。

双击标签栏空白处可新建，名称按“新文件 1、2、3”递增并避开重复；按住标签左右拖动可排序。
双击正文选择连续中文或英文片段，三击选择整条逻辑行，屏幕折行不会截断所选内容。
行号旁**橙色**为相对上次保存尚未保存的修改，**绿色**为本次会话已经保存的修改。
保存恢复草稿不代表保存原文件；极端大量重复行改写的标记范围可能较保守。

## 阅读、搜索与格式

Markdown 文件打开后默认全宽预览，点击“编辑原文”才显示源码，点击“返回预览”继续阅读。
编辑区区分标题、标记、行内代码和链接颜色；点击“分屏编辑”可左侧编辑、右侧阅读，
拖动中间分隔线调整宽度。预览支持标题字号层次、强调、代码背景、引用边线、列表和基础表格，
编辑后稍等片刻自动更新，关闭预览即返回完整编辑区。分屏状态暂不随重启保存。
完整阅读模式保留目录与搜索的原文位置映射。解析为轻量原生实现，不提供完整 CommonMark/GFM。
表格分隔线兼容一个或更多短横，支持可选首尾竖线、转义竖线及行内代码中的竖线。
表格按内容分配列宽，序号列较窄，长路径和说明列获得更多空间；窄窗口内自动折行。
表格支持分隔线冒号指定的左、中、右对齐，保留单元格内代码和强调样式。
宽表格右键选择“展开表格（横向滚动）”，在独立窗口完整阅读，不改变原文及主预览选区。
调整窗口大小、侧栏或阅读宽度时会重新排版当前内容，保留选区和查找位置。
调整字号时标题、代码、表格与图注同步缩放，分屏调整版心不会重建文档或回到开头。
预览显示本地相对/绝对路径的 PNG/JPEG 等位图及 `data:image/png;base64,...` 内嵌 PNG，中文、空格和 URL 编码路径均可使用。
相对路径基于 Markdown 文件位置；未保存文档请先保存到合适位置再引用相对图片。
图片异步加载、按正文宽度等比缩放，缺失或损坏会显示说明；网络图片不下载，HTML 不执行，链接只显示文字。
点击已加载图片可放大查看；窗口内可缩放、适应窗口、查看解码原图及复制位图，Ctrl+滚轮缩放，Esc 关闭。
富预览支持 50 万正文字符，内嵌图片 Base64 负载不占正文额度，仍受 50 MiB 文件上限与图片解码资源限制。
单图最多 16 MiB、3200 万原始像素，单边不超过 32768；解码最长边为 4096。
单篇最多 32 张图、64 MiB 图片数据及 4800 万解码像素，超限会提示；远程与网络盘图片不加载。
正文与阅读视图按 UTF-16 块级近似定位。
阅读中查找搜索的是可见文本，输入后自动定位并突出选中一个匹配项，继续输入不会丢焦点；替换会回到源文编辑。
关闭查找会回到查找前的阅读段落；目录随实际阅读章节更新，主动点击目录后可用“返回位置”回跳。
会话保存实际屏幕可见段落，滚动不会改变用于复制的选区。未改动正文往返预览会复用现有文档。
打开时显示读取、解析、排版阶段及已用时间；点击“取消”停止当前任务，已加载原文和编辑保留。
帮助菜单“打开与阅读诊断”只展示当前运行的阶段耗时，不记录文件名、路径、正文或图片。

预览中选中内容按 Ctrl+C，或右键/编辑菜单“复制”，会提供富文本与纯文本格式。
标题、表格、列表保留结构，已加载图片随内容复制；只复制选区，不带出未选内容。
不需要手工全选时，可点击“复制全文（含图片）”；复制后不会改变原文或当前选区。
“复制 / 导出”可选择纯文本、Markdown 源文、当前代码块或当前表格；复制块前先将光标或选区置于目标块。
全文复制与 HTML 导出最多等待已创建图片 5 秒，可取消；未加载或超限图片会保留明确占位并提示遗漏。
图片尚未加载或超过复制上限会有提示，加载完成后可重试。编辑源码时 Ctrl+C 仍复制 Markdown 源码。
复制图片最多 32 张，重新编码的 PNG 单张最多 4 MiB、合计 12 MiB；HTML 输出最多 20 MiB，
每份原生富文本载荷最多 64 MiB。超过整体转换预算时，选区复制回退原生格式，全文按钮会提示分段复制。
分屏编辑后立即复制全文会先同步最新文字；新图片仍需等待加载完成。
粘贴时请选择目标应用的“保留源格式”或富文本选项；纯文本输入框及主动丢弃 HTML/图片的应用只能接收文字。
当前不导出 Mermaid 图形为图片，图表可选中保留的源码复制。
文件菜单“导出自包含 HTML”可保存阅读正文、表格和内嵌图片，无需携带图片文件夹。
输出为 UTF-8，最多 20 MiB；不会下载网络图片、执行脚本，也不能覆盖当前任一已打开的原文。

轻阅已运行时，从“打开方式 → 轻阅”或命令行打开文件会交给现有窗口，无需先退出。
切换标签或重新回到窗口时会检查原文件更新：已保存的文档自动刷新；存在未保存修改时保留编辑并提示冲突。
磁盘文件被删除或暂时无法读取时不会清空正文，下次切换或激活可重试，保存时仍检查外部冲突。

`mermaid` 代码围栏中的 `sequenceDiagram` 可离线显示为时序图。粘贴 Markdown 后，
点击“返回预览”查看图形，也可选择“分屏编辑”；代码编辑区继续显示原文，宽图使用图形底部水平滚动条。
预览可展开“查看 / 复制 Mermaid 源码”；返回编辑可查看完整原文。
安装目录的 `示例/时序图.md` 提供可直接打开的样例。

当前支持 `participant` / `actor`、`as` 别名、隐式角色、独立行 `%%` 注释、单独的 `autonumber`，
`->` / `->>` / `-->` / `-->>` / `-x` / `--x` / `-)` / `--)` 消息、自调用，
以及 `Note over A,B`、`Note right of A`、`Note left of A`。`<br>` 可换行，其他 HTML 按文字显示。
`->` / `-->` 是无箭头连线，`->>` / `-->>` 是实心箭头，`-)` / `--)` 是开放箭头。
消息、Note 和角色别名中的 `%%` 保留为文字。每条语句请独立成行，暂不支持 ASCII 分号 `;`，
含分号的多语句或实体写法会整图提示并保留源码；中文分号 `；` 可正常显示。
流程图、`alt` / `loop` 等分支循环、激活和配置指令暂不支持，整图显示原因与完整源码，
不会省略不认识的指令后继续绘图。
每图限 32,000 个 UTF-16 单元、1,000 行、20 个角色、200 个事件、单标签 2,000 单元；
每篇最多 12 个图形代码块、64,000 单元图表源码、400 个图形事件，超出部分保留源码并提示。

JSON 字段为蓝色、字符串为暖橙色、数值为青绿色；“JSON 结构”可展开或折叠对象和数组，
返回编辑后仍是原文。严格 JSON 格式化保留重复键、顺序、大数和数字原始词法，中文直接显示。
JSONC 格式化保留注释与尾逗号，注释位置可能调整，不支持 JSON5。
TXT 整理行尾空白、多余空行与缩进，保留正文分段和行内空格；Markdown 格式化保护代码、
表格、frontmatter 和两个空格的手动换行；XML 保守缩进，禁止 DTD。
格式化通过 Ctrl+Z 一次撤销，Ctrl+S 才写回原文件。

新增 JavaScript、TypeScript、Python、Java、C#、SQL、HTML、CSS、Go、Rust、Shell、
PowerShell、TOML、CSV 的类型与扩展名识别。这些类型尚无完整语法着色与格式化器，
“整理空白”会先显示前后对比供确认。YAML 仅检查缩进 Tab，INI 无完整校验。

单文件最多 50 MiB；富预览和 MD 分屏支持 500,000 个正文 UTF-16 单元，内嵌图片负载单独计限；
超过上限改用原文只读阅读。JSON 结构限 2,000,000 单元；极长行/大文档回退原生文字显示。
搜索最多 5,000,000 单元，查询长度、匹配数量和替换结果有上限，正则有超时保护。
大文档的编辑、状态计算与恢复草稿会增加耗时，本轮小文件测量不代表大文件性能保证。

## 保存与冲突

恢复草稿不会自动写回原文件。修改后请用 Ctrl+S 保存。
原文件被其他程序改变时，保存会提示明确覆盖、另存为或取消。
占用、只读、权限不足、重解析点或多硬链接文件会保守拒绝原位保存，可选择新的普通文件另存为。
保存失败会保留窗口正文。混合换行文件修改后，需明确统一为 LF 或 CRLF。

重命名只修改磁盘名称，继续保留尚未保存的正文；同名目标不会覆盖。
保存使用同目录临时文件及 Windows 文件替换能力，尽量保持目标 ACL。
对不支持可靠替换的网络盘或文件系统，可能需要另存为。

## 会话与恢复草稿

默认数据目录：`%LOCALAPPDATA%\Qingyue`。
`Settings.json` 保存偏好与最近记录，`Session.json` 保存标签状态，`Drafts` 保存独立恢复草稿。
这些文件是本机明文数据，不提供加密。敏感内容可在“文件 → 会话与恢复草稿”中关闭或排除。

编辑后约 1.5 秒开始保存不可变草稿快照，磁盘写入串行执行。正常退出会再次等待持久化完成。
关闭单个未保存标签可保存、放弃或取消；退出程序另可选择保留草稿，前提是该文档已启用恢复。
恢复失败会显示提示并隔离损坏数据，不会把草稿静默写回磁盘。

恢复最多 200 个文档、草稿序列化总量最多 150 MiB。清除草稿后，当前打开的文档需要单独重新启用恢复；
关闭恢复并不等于保存原文。Windows 与 Mac 的会话数据彼此独立。

开发和测试可通过 `QINGYUE_SUPPORT_DIRECTORY` 指定独立数据目录。
