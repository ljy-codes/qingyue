# 轻阅跨平台版本与功能对齐规则

这份规则用于后续 Mac 与 Windows 发布，当前只记录约束，不修改 Windows 客户端实现。

## 版本号

- Mac 使用偶数产品版本：0.4.0、0.6.0……；Mac 构建号同步使用偶数：14、16……。
- Windows 使用奇数产品版本：0.19.0、0.21.0……；Windows 的构建号和安装器版本沿用 Windows 发布流程。
- 版本号分配前先检查两端最新 tag，不能复用已经发布的版本号。

## 功能对齐

- 两端对外承诺的阅读、编辑、搜索、Markdown、图片、表格、Mermaid、工作区、阅读清单、书签、批注、恢复和导出能力应保持同一功能矩阵。
- UI、文件对话框、文本排版、剪贴板、签名、安装器和系统菜单允许使用各自平台的原生实现；平台差异必须写入对应使用说明和验收记录。
- 新增功能先更新功能矩阵，再分别补 Mac 与 Windows 的实现和回归测试；不能只在一端宣传已支持。

## GitHub 保留策略

- Mac 只保留最新 Mac tag 和最新 Mac 交付包；旧 Mac tag 仅在需要追溯时保留，清理前先确认没有外部链接依赖。
- Windows 只保留最新 Windows tag 和最新 Windows 交付包。当前没有重新核对 Windows 端，因此本轮不删除、不改写 Windows 分支、tag、代码或安装器。
- Mac 与 Windows 的发布记录分开，不能用 Mac 的验收结果替代 Windows 的实机验收。

当前 Mac 目标为 **0.4.0 · Mac 构建 14**；Windows 版本号和 GitHub 保留动作待在 Windows 环境完成核对后再处理。
