# 轻阅 0.14.0：层次排版、表格编辑、截图插图

用户于 2026-11-17 批准执行上轮建议的前三项，沿用指定目录及现有 Windows 开发分支持续推进。

## 目标与边界

- Windows / .NET 10 / WPF，Core 不增加第三方依赖。
- 文件仍为标准 Markdown；所有正文修改进入既有撤销、安全保存、草稿、外部修改保护链路。
- 保留中文组合输入、源码 UTF-16 坐标、原生选区和撤销。非 Markdown 编辑、Mac 工程不作功能变更。
- 保持本地处理，不加入云同步、账号、历史迁移。
- 继续在用户指定的干净 `feat/windows-client` 工作区实施，不另外复制项目。

## 一、层次排版

编辑区增加细淡缩进参考线，区分真实列表层级与代码内容，跟随字号、滚动、软换行和明暗主题。阅读及预览继续使用真实嵌套 List/ListItem，补齐列表内引用、标题和表格等块的容器归属，复制与 HTML 导出保留同一结构。

长行悬挂缩进先以真实 WPF 控件验证：不能只移动绘制文字而让光标、选区、鼠标命中和输入法留在原位置，不能向文件写入伪空格。如果原生 TextBox 不能提供可靠的段落缩进，本轮明确记录验证结论，交付参考线与阅读容器排版；编辑器替换作为独立架构工作，不以假效果冒充完成。

## 二、表格编辑

新增纯 Core 的 `MarkdownTableEditing`，产生与现有结构命令一致的 `MarkdownEdit`：

```csharp
public enum MarkdownTableAction
{
    NextCell, PreviousCell, InsertRow, DeleteRow, InsertColumn, DeleteColumn,
    AlignLeft, AlignCenter, AlignRight, InsertTable
}
public static MarkdownEdit? Apply(string text, int start, int length, MarkdownTableAction action);
public static MarkdownEdit? FromTsv(string text, int start, int length, string tsv);
```

- 表格内 Tab / Shift+Tab 切换单元格，末格继续时追加行；Enter 插入下一行。
- 工具栏提供插表、增删行列及当前列左/中/右对齐。
- Excel/WPS 的制表文本可经“粘贴为表格”转换；普通粘贴保持原有文字行为，图片剪贴板单独接管。
- 保护围栏代码、转义竖线、行内代码中的竖线、CRLF、中文与代理对。
- 行列操作保留已有单元格内容及对齐，最少一列，删除表头或分隔行采取明确保守行为。
- 至多 32 列、1024 单元格、100000 字符；不接管不完整表格或超预算内容。

## 三、截图与本地图片插入

- Markdown 源文编辑中截图 Ctrl+V，或工具栏选图，或拖入本地位图，保存为文档旁 `<文档名>.assets` 中的 PNG 并插入相对路径。
- 未保存文档先通过既有另存流程确定位置，取消则不创建附件。
- 以不可变图片和正文/路径/选区快照执行后台写入；返回时验证仍为同一文档与同一编辑状态，拒绝过时结果。
- 文件名碰撞使用 CreateNew 避免覆盖，URI 转义路径，拒绝网络路径和重解析目录，限制单图编码字节和像素。
- 写入或插入失败只清理本次新建附件。成功插入后撤销只撤销 Markdown，保留附件以支持重做；不自动删除已有图片。
- 多文件或非图片拖入仍沿用打开文件；只在明确的 Markdown 编辑区接管单张受支持图片。
- 图片显示、复制、导出继续使用既有本地图片渲染器及资源预算。

## 验收

Core 表格行为和真实 WPF 输入/撤销、布局、图片写入与预览均需验证；每个行为先添加失败用例再实现。最后运行完整 `scripts/test.ps1`，隔离安装/卸载检查、便携启动、产物哈希验证。实际结果写入 `docs/test.md`，同步版本、说明、示例及发布说明。
