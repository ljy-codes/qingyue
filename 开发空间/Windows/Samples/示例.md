# 欢迎使用轻阅

本机文本，安静阅读。

轻阅 Windows 版可以打开文本、编辑配置，也可以把 Markdown 切换为原生阅读视图。
原文件由你主动保存，恢复草稿另存在本机。

## 从这里开始

- 按 Ctrl+O 打开文件，Ctrl+S 保存。
- 按 Ctrl+R 切换阅读与编辑，Ctrl+F 查找。
- 点击“MD 预览”开启左右分屏，左侧编辑原文，右侧查看排版。
- 点击“格式化”或按 Ctrl+Alt+F 整理 Markdown，Ctrl+Z 可一次撤销。
- 按 Ctrl+B 展开侧栏，Ctrl+Shift+O 查看目录。
- 按 Ctrl+Shift+F 进入专注，再按一次退出。

> 自动保存的是恢复草稿。重要内容仍请手动保存原文件。

## 配置示例

```json
{
  "name": "轻阅 Windows",
  "local": true,
  "number": 9007199254740993
}
```

格式化 JSON 时会保留大整数和指数的原始写法。
JSON 编辑区区分字段、字符串与数值颜色，还可通过“JSON 结构”展开或折叠层级。

| 格式 | 阅读 | 编辑 |
| :--- | :--- | :--- |
| TXT | 原文阅读 | 支持 |
| Markdown | 分级标题、引用、代码和表格 | 分色编辑与格式化 |
| JSON | 保留缩进 | 检查与格式化 |

标题、段落、列表、引用和代码各有层次；预览只改变显示，保留原始 Markdown。
图片不会联网加载，HTML 不执行，链接不会自动打开。解析为轻量原生实现。
