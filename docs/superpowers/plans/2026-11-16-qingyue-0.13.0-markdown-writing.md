# Qingyue 0.13.0 Markdown Writing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成即时列表、稳定编辑、快捷操作、轻量工具栏和分屏定位五项已批准需求。

**Architecture:** 原生 TextBox 继续负责输入、IME、选区与撤销；绘制层只改变列表标记的视觉。Core 处理文本命令与嵌套列表语义，WPF 构建真实嵌套列表并复用已有源文映射。

**Tech Stack:** .NET 10, WPF, C#, existing executable regression suites.

**Spec:** `docs/superpowers/specs/2026-11-16-qingyue-0.13.0-markdown-writing.md`

## Global Constraints

- Windows / .NET 10 / WPF；Core 不增加第三方依赖。
- 不增加云同步、账号或历史数据迁移。
- 文件保存标准 Markdown，显示圆点不得替换为字面 `•`。
- 保留原生编辑器的源码偏移、选区、中文输入和撤销；仅明确保存时修改原文件。
- 保留现有图片、批注、搜索、恢复与取消预算。
