# 欢迎使用轻阅

一个在本机工作的轻量文本阅读与编辑器。

## 试试看

- 调整字体大小，让中文阅读更舒服。
- 切换阅读模式，专注当前文档。
- 在多个文件标签间切换。
- 使用查找与替换快速定位内容。

> 文件直接保存在你的 Mac 上，保存由你决定。

## 配置示例

```json
{
  "name": "轻阅",
  "local": true,
  "theme": "dark"
}
```

正文可以包含 **重点文字**、*强调*、`行内代码`和[网站链接](https://example.com)。

本版本的 Markdown 阅读视图采用原生文本排版，支持基础表格和任务列表，复杂嵌套排版会继续完善。
