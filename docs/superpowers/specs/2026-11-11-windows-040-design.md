# 轻阅 Windows 0.4.0 设计方案

## 目标

0.4.0 将轻阅收敛为“以 Markdown 阅读和图文复制为核心，编辑能力随时可用的本地阅读器”。本版本解决阅读态顶部占用过大、Markdown 预览往返和缩放不稳定、查找反馈不完整、图片文档可能卡住，以及安装/卸载步骤过多的问题。

产品名称继续使用“轻阅”，保留现有 `Qingyue` 安装目录、用户数据目录、注册表产品标识和快捷方式，避免无必要的数据迁移。

## 用户可见行为

### 阅读态

- 阅读态隐藏菜单栏、品牌大标题和编辑专用工具，只保留一条轻量操作条。
- 操作条保留侧栏、文档标题/保存状态、查找、目录、字号/主题和编辑入口。
- “格式化”“JSON 结构”“分屏编辑”等编辑操作在阅读态隐藏或降级到更多操作中。
- 单文档阅读时不再通过大品牌区重复显示产品名和副标题。
- 阅读态底部优先显示阅读状态、字符量和阅读进度；编码、换行、行列号等技术信息只在编辑态显示。
- 进入阅读态时将位置吸附到最近标题或完整段落开头，并在视口顶部保留稳定留白。目录跳转后的标题也保持留白。

### 查找

- 查找栏改为紧凑的浮层/轻量区域，减少对正文高度的占用。
- 搜索完成后立即自动选择第一处匹配并显示 `1 / N`；无匹配显示“没有匹配”。
- Enter、Shift+Enter 继续前后跳转，Esc 关闭查找并恢复原文焦点。
- 搜索匹配在编辑态和阅读态都保持选中/高亮，不覆盖搜索框焦点。

### Markdown 阅读、编辑与复制

- Markdown 打开默认全宽阅读预览。
- 点击“编辑原文”进入源码编辑；编辑完成后可以明确返回阅读预览，且返回时保留源文位置和阅读位置。
- Markdown 分屏仍作为可选操作，不作为默认阅读布局。
- 预览使用稳定的正文版心，默认阅读宽度为 680px；窗口缩放、侧栏切换和主题变化只重排现有文档，不重复解析或重新解码图片。
- Markdown 预览继续支持标题、列表、引用、代码、表格、图片和 Mermaid。图片采用后台加载、单文档图片数量/像素/字节预算和取消机制；过量或失败图片显示短提示，不把 data URI 或内部 token 泄漏为正文。
- 全文复制默认提供 HTML、RTF、XamlPackage 和纯文本数据，图片以内嵌资源写入 HTML/XamlPackage；复制 Markdown 源文、当前代码块和当前表格继续可用。
- Markdown 复制的 HTML 使用稳定的标题、段落、列表、表格和图片结构，方便粘贴到 Word、腾讯文档等目标应用。
- 普通 txt 继续支持阅读态复制和基础整理；JSON、Markdown 等已有格式化入口保持兼容。

### 文件刷新

- 切换标签、窗口激活和切回对应文件时检查原文件是否被外部修改，并在无本地未保存编辑时自动展示最新正文。
- 有本地未保存编辑时保留编辑内容并提示冲突，不覆盖用户输入。
- 阅读态、编辑态和 Markdown 分屏在接纳外部更新后同步刷新，并尽量保留选区和滚动位置。

### 安装

- 安装向导只保留一页设置和一页安装进度。
- 设置页只包含安装地址和桌面快捷方式选项，默认安装位置可编辑并支持选择目录。
- 安装阶段只显示一个明确的实际进度条和简短状态，不展示冗长的内部步骤。
- 安装结束后自动关闭；如果用户勾选立即启动，则在关闭前启动轻阅。
- 现有安装目录校验、降级保护、占用检查、链接保护和当前用户安装权限保持不变。

### 卸载

- 卸载向导只保留一页选项和一页进度。
- 默认选择“保留用户信息”。
- 用户可以选择“彻底卸载并清理用户信息”；该选项删除 `%LOCALAPPDATA%\Qingyue` 下的设置、最近文件、会话和恢复草稿。
- 彻底卸载同时清理专用安装目录内由安装器写入的程序文件；如果目录中存在用户自行添加文件、链接或目录不安全，则保留并给出结果。
- 外部文档、其他目录、安装根目录、桌面和开始菜单中不属于轻阅的内容不删除。
- 卸载完成后自动关闭，不再展示多余的“下一步/完成”页面。
- 静默卸载继续默认保留用户信息，并保留现有失败时保留卸载入口的安全策略。

## 技术方案

### 主窗口状态

继续使用 `RefreshCurrent` / `RefreshPresentation` 作为可见性和状态同步入口，在 XAML 中增加阅读态轻量工具条需要的命名控件，避免把状态判断散落到点击事件中。阅读态切换时统一调用一个可测试的可见性方法，编辑态恢复完整工具栏和底部技术信息。

阅读位置吸附使用现有 `ReadingModel` 的 block/heading 源映射：如果当前源位置落在标题范围内，定位到标题开始；否则定位到所在内容块的开始。吸附只改变视图指针，不改变文件文本、编辑器选区或撤销栈。

### Markdown 预览

保留 `MarkdownPreview` 的纯本地文档边界和 `RenderedReading` 的导航映射。预览构建继续使用防抖和异步构建，但在宿主替换文档前检查当前标签、文本版本和取消令牌；旧任务不能覆盖新标签或新正文。`UpdatePresentation` 只修改已有 FlowDocument 的版式参数。

复制继续以 `ReadingClipboard` 和 `ReadingHtmlExport` 为边界。HTML 导出明确写入 `thead/tbody`、标题层级、段落、列表和图片 `data:`/本地资源，保持纯文本回退。

### 主题

补充阅读画布资源，使工具面板与正文画布有明显层次：

- 浅色窗口 `#F6F4EF`，面板 `#EFEAE2`，阅读画布 `#FFFDF8`，正文 `#262A2F`，主操作蓝 `#1F63C4`。
- 深色窗口 `#191B1F`，面板 `#23262B`，阅读画布 `#2A2825`，正文 `#E8E2D8`，主操作蓝 `#2F6FDB`。
- 标题默认使用正文色；蓝色用于链接、选中状态和主操作。
- 主题切换继续覆盖现有弹出控件和隐式样式，并通过现有对比度测试验证正文和下拉列表可读。

### 安装器页面

保留 `wizard-pages.nsh`、`uninstall-pages.nsh` 和 `uninstall-actions.nsh` 的现有宏边界，删除安装完成页、卸载欢迎页和彻底清理确认页。安装路径设置页直接进入 `instfiles`；卸载选项页直接进入 `instfiles`。通过 `AutoCloseWindow true` 和完成后关闭行为避免出现额外按钮。

卸载清理仍由 `safety.cpp` 的受限 `PurgeData` 和生成的文件清单负责。彻底卸载时先校验用户数据路径和安装标记，再删除清单文件、快捷方式、注册表和空的专用安装目录；遇到非空目录、链接或删除失败则保留剩余内容和卸载入口。

## 验收标准

1. 阅读态首屏不再显示大品牌区和编辑工具栏，正文有效高度明显增加。
2. Markdown 打开默认为全宽预览，点击编辑后可返回预览，窗口连续缩放不乱版。
3. 搜索第一次完成后直接显示 `1 / N`，当前匹配可见且高亮。
4. 从编辑中段进入阅读后，视口从标题或完整段落开始。
5. 含大量本地图片或长 data URI 的 Markdown 在 UI 线程有响应，旧图片任务不能覆盖新内容。
6. 复制 Markdown 到 Word/腾讯文档类富文本目标时，标题、表格和图片仍保留结构；纯文本回退可读。
7. 浅色和深色主题正文、面板、表格表头有层次，正文和控件对比度达到现有测试要求。
8. 安装只需要选择路径、确认安装，进度页只有一个进度条，完成后自动关闭。
9. 卸载默认保留用户信息；彻底卸载能清理用户数据和专用安装目录，同时保护外部文件和链接。
10. 既有核心、Markdown、图片、复制、外部刷新和安装器安全测试全部通过。

## 风险与控制

- WPF FlowDocument 对超大文档仍有构建成本：通过现有 50 万字符限制、图片预算、异步分段让出 UI 线程和取消旧任务控制风险。
- 富文本粘贴效果由目标应用决定：提供 HTML/RTF/XamlPackage/纯文本多格式回退，并加入导出结构测试。
- 卸载清理存在误删风险：继续使用专用产品标识、路径规范化、链接检测、安装标记和失败保留策略；不使用通配符删除用户目录。
- 阅读态隐藏控件可能影响旧 UI 自动化：保留可访问名称和菜单命令，更新测试同时覆盖阅读态和编辑态。
