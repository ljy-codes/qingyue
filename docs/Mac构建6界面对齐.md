# Mac 构建 6 界面对齐与验收

日期：2026-11-13。产品版本保持 **0.1.0**，Mac 构建编号 **6**。本轮拉取了仓库最新 Windows 分支（`a5831d0`，Windows 0.8.0 build 3），并以其中已经稳定的 0.3.0 主窗口层级、主题和阅读操作作为 Mac 界面基准。Windows 0.4–0.8 的书签、差异窗口、图片缓存等后续能力记录为后续 Mac build 7+ 任务；Windows 源码和安装包不在本轮修改范围。

## 对齐层级与度量

| 区域 | Windows 基准 / Mac 目标 |
| --- | --- |
| 窗口 | 默认 1120×762，最小 820×492；保留 Mac 标题栏 |
| 菜单 | 全宽顶行，文件/编辑/搜索/视图/标签/帮助，保持对应功能分组 |
| 品牌栏 | 20 点水平、15 点垂直留白；左侧 36 点侧栏图标、间距 14、品牌 22/11；右侧打开文件/保存/阅读或编辑/专注，间距 8 |
| 标签栏 | 横跨窗口，在侧栏上方；右侧“+”；选中项为面板底色和强调色下划线 |
| 搜索 | 标签下方横跨全宽；查找、选项和替换分别成行，替换按请求显示 |
| 主体 | 左侧 218 点，右侧上下文工具栏和文档；连续面板，不采用独立大圆角卡片 |
| 侧栏 | 最近打开、文档目录；文件名和文件夹两行；清除最近记录、底部提示 |
| 文档工具 | 格式化 → JSON 结构 → 分屏编辑 → 图文复制 → 复制/导出 → 返回位置 → 提示，按类型/状态显示 |
| 底栏 | 路径/状态与位置上下两行；右侧语言 150、编码 138、换行 178，间距 8；阅读模式仍可见 |
| 深浅主题 | 使用 Windows ApplyTheme 的石墨灰/暖灰及浅色值；强调、禁用、悬停和选中层级对应 |
| 专注 | 隐藏应用内菜单、标签、侧栏；保留品牌操作与正文工具，不因进入专注而隐藏退出入口 |

## 保留的平台行为

Mac 红黄绿窗口控制、系统文件对话框、系统字体回退、`⌘` 快捷键与系统级应用菜单保留。这里的视觉对齐是应用内部布局与样式对齐，不假称各平台字体栅格、标题栏和系统弹出菜单逐像素相同。
