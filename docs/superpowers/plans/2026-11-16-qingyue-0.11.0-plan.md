# 轻阅 0.11.0 Windows P0 实现计划

## 目标

在本机完成三个 P0 闭环：

1. 工作区：打开文件夹、文件树、类型过滤、默认忽略 `bin`、`obj`、`.git`、收藏目录。
2. 全局搜索：跨文件普通搜索、正则、文件名过滤、上下文、跳转行、替换预览。
3. 阅读清单：固定文件、最近阅读、已读/未读、阅读进度、恢复上次阅读位置。

约束是所有数据留在本机，继续使用 WPF 和现有 `DocumentFile` 安全保存链路，不引入云同步、账号、WebView 或第三方运行时。

## 实现顺序

1. Core 数据模型和服务
   - 本地工作区扫描器：边界、忽略目录、重解析点、大小和条目上限。
   - 全局搜索服务：文件名通配、文本解码、上下文、正则超时、替换预览。
   - 阅读清单存储：原子保存、版本校验、路径规范化、条目上限。
2. Core 失败测试
   - 验证目录扫描、忽略规则、类型/文件名过滤。
   - 验证跨文件搜索、正则捕获组替换、上下文和行列信息。
   - 验证阅读清单持久化、固定/读写状态、进度和损坏文件隔离。
3. WPF 集成
   - 左侧工作区树和阅读清单。
   - 全局搜索窗口及跳转、替换预览。
   - 打开文件、阅读位置和清单状态的联动。
4. 文档和版本
   - 更新使用说明、变更日志、Windows 版本号。

## 验证

先运行新增 Core 测试确认接口按预期失败，再实现生产代码；完成后运行：

```powershell
pwsh -NoProfile -File '开发空间/Windows/scripts/test.ps1' -Configuration Release
```

并检查工作区只包含本次 0.11.0 变更。
