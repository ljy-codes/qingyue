# 轻阅 Windows 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将轻阅 Windows 客户端升级为阅读优先的 0.4.0，并压缩安装/卸载流程、修复 Markdown 预览和复制体验。

**Architecture:** 在现有 WPF 主窗口、`ReadingModel`/`RenderedReading`、`MarkdownPreview`、`ReadingClipboard` 和 NSIS 安全安装器上做局部修改。主窗口通过统一的阅读态呈现方法控制工具栏和状态栏；Markdown 继续使用现有异步构建、图片预算和源文映射；安装器通过减少页面宏和保留原生安全校验缩短流程。

**Tech Stack:** .NET 10 WPF, C#, FlowDocument, NSIS, native C++ helper, PowerShell regression scripts.

**Spec:** `docs/superpowers/specs/2026-11-11-windows-040-design.md`

## Global Constraints

- 产品名继续使用“轻阅”，不迁移现有安装目录、用户数据路径和注册表产品标识。
- 产品版本为 `0.4.0`，Windows 构建号为 `2`，文件版本为 `0.4.0.2`。
- 不删除用户外部文档；卸载删除必须限定在安装器清单、专用用户数据目录和经过校验的专用安装目录。
- 生产代码修改前先添加一个能证明目标行为缺失的失败测试，并观察测试按预期失败。
- 保持现有当前用户安装、降级保护、链接保护、占用检查和冲突保护。
- 每个任务完成后运行该任务的最小测试，再继续整体验证。
