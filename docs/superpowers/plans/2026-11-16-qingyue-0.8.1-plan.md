# Qingyue 0.8.1 Release Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe Windows file associations, CI validation, optional Authenticode signing and current release documentation.

**Architecture:** Keep registry behavior in the NSIS installer and generate no machine-specific state in the repository. File extensions point to one stable ProgID through `OpenWithProgids`; the existing default association stays untouched. CI calls the repository’s existing PowerShell build/test entry points.

**Tech Stack:** NSIS, PowerShell, .NET 10, GitHub Actions, Authenticode `signtool.exe`.

**Spec:** `docs/superpowers/specs/2026-11-16-qingyue-release-roadmap-design.md`

## Global Constraints

- Registry writes must be limited to the `Qingyue` ProgID and its `OpenWithProgids` values.
- The installer must remain usable without a certificate.
- Existing installer tests and existing file/session behavior must remain green.
- No secrets, certificate passwords or signed binaries are committed.
