日期：2026-11-09。基于当前未提交的 Windows 构建 1 继续开发，保留已有修改。

## 目标与约束

- 安装：首页选择路径后直接安装，显示真实进度与阶段，保留离线自包含安装；用实测解释包体与速度变化。
- 卸载：继续默认保留资料，彻底清理需明确选择及再次确认；保留按清单删除、未知文件保护。
- 新建：标签栏空白双击新建；自动命名“新文件 1”等，避开当前和恢复名称。
- 标签：按住拖动排序，保留关闭、重命名和菜单左右移动替代操作，顺序可恢复。
- 修改提示：行号边橙色条标记未保存变更，保存后转绿；绿色记录本次会话已保存修改，撤销后重新比较。
- 选择：双击选中文/英文连续片段，三击选中逻辑行，软换行不截断。
- 格式化：顶部明显入口及快捷键。JSON 无损保留大数、重复键、中文；TXT 整理空白、保留分段，单步可撤销；其他语言如未有可靠格式化器只标为整理空白。
- JSON 展示：蓝色键、暖橙字符串、青绿数值，缩进、行号和可折叠结构视图；编辑与只读结构视图分开，源文不因浏览而改变。
- 易懂：换行显示 Windows / Linux / 旧 Mac / 混合并解释用途；阅读宽度改用直观名称。
- 外观：保留认可的石墨灰与浅色主题；帮助、关于改为主题一致、有蓝青强调色的窗口。
- 语言：保留既有枚举值以兼容会话，追加常见语言识别，明确高亮/格式化/校验能力。
- 不修改 macOS、EnvDock；不提交、推送、发布；不关闭用户未保存窗口。

## 范围与验证

1. 安装分支：installer、publish/build-installer 脚本；量化体积、单页与进度；运行目录、保留与清理隔离测试。
2. 格式化分支：Core 文本服务/语言目录；先覆盖数据完整性、TXT 边界，再实现。
3. 编辑分支：EditorTab 与独立交互分部；覆盖命名、变更行、片段/逻辑行、排序与恢复。
4. 界面集成：MainWindow、Dialogs 与新增语法/结构控件；保留原 TextBox 搜索、撤销、编码和阅读位置接口。
5. 发布验收：完整回归与新场景、深浅色目检、构建 0.2.0.2 安装包、保护资料进行本机更新（如旧窗口占用，明确提示而不强杀）。
