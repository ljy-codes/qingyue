# Qingyue 0.10.0 Markdown and Mermaid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve common GFM compatibility and add a bounded offline Mermaid flowchart renderer while preserving source mapping and safe fallback.

**Architecture:** Extend the existing `ReadingModel` inline parser with reference definitions and autolinks, then keep the same block mapping contract. Add a Core `MermaidFlowchart` parser that produces bounded nodes/edges and a WPF `MermaidFlowchartView` that draws vector geometry with the same theme and budget hooks as sequence diagrams.

**Tech Stack:** C#/.NET 10, WPF, regular expressions with non-backtracking mode, existing Markdown and Mermaid test harnesses.

**Spec:** `docs/superpowers/specs/2026-11-16-qingyue-release-roadmap-design.md`

## Global Constraints

- Unknown Markdown and Mermaid syntax must remain visible as source.
- No JavaScript, WebView, external image or network dependency may be added.
- Source/display offset mapping must remain monotone and bounded.
- Mermaid input must obey existing document, character, participant/node and event/edge budgets.
