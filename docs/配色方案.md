# 轻阅配色方案 · Palette Atlas 版

基于 Palette Atlas 配色知识库与对比表重新整理。原始知识库不属于本仓库；下文保留本项目需要复核的令牌、对比度和落地关系。目标是把配色归纳为 **3 个设计族 × 浅/深两模式**，同时保留产品实际的 7 套主题。

## 结论

| 主题 | 定位 | 适用 |
|---|---|---|
| 墨蓝专业 | 默认主题：冷静、专业、长时间阅读不疲劳。 | 日常阅读 / 编辑 |
| 暖纸阅读 | 长文阅读主题：暖灰纸感、低蓝光、正文更柔和。 | 长文阅读 / 写作 |
| 青绿效率 | 配置 / 数据 / 工作台主题：青绿强调、冷白底、层级清楚。 | 配置 / 数据 / 工作台 |

**产品默认主题：经典。** 在设计族中，经典归入墨蓝专业的基础蓝灰分支；暖纸阅读作为沉浸阅读预设，青绿效率作为配置/数据场景预设。

## 设计族与产品主题

设计族是配色方案的说明层，不是新的主题选择项。每个 `ReaderThemeID` 仍保留独立的浅色/深色令牌、语法高亮和选区颜色；下表只描述它们的主要使用语境。

| 设计族 | 产品主题 | 对应语境 |
|---|---|---|
| 墨蓝专业 | 经典、海盐蓝、墨蓝深色 | 通用阅读、冷色工作区、深色长文阅读 |
| 暖纸阅读 | 咖色暖读、烟雨紫 | 暖纸长文、安静阅读和柔和低刺激场景 |
| 青绿效率 | 青瓷古色、纸白极简 | 配置/数据、轻量工作台和高留白编辑场景 |

这份映射按产品体验归类，不宣称每个主题都复刻设计族的单一色板；实际值以 `ReaderThemeCatalog.definition(for:dark:)` 为准。

## 三条硬规则

1. 正文 ≥ 4.5:1；大字、图标、控件、焦点态 ≥ 3:1。
2. 颜色数量：1 个主色 + 1 个强调色 + 一组中性色；语义色单独使用。
3. 面积比例：底色 60–70%，文字与主体 20–30%，强调色 5–10%。

## 落地到轻阅

`ReaderThemeDefinition` 对应关系：

| 主题 token | 轻阅字段 |
|---|---|
| bg / surface / surface2 | `window` / `panel` / `main` |
| surface3 / border | `main` 深一档 / `border` |
| text / muted / subtle | `text` / `muted` / `muted` 的淡化版 |
| accent / accentHover / accentSoft | `accent` / 自算 hover / `selection` |
| accentFg | `accentForeground` |
| selection | `selection` |
| success / warning / danger / info | `saved` / `unsaved` / 状态色 / 链接色 |
| string / number / key / comment / keyword | `EditorPalette` |

## 关键取舍

- 知识库的 `success #12A594` 在浅底上约 2.91:1，不足 3:1；主题中改用 `#0F766E`（约 5.47:1）。
- 知识库的 `accent #0D9488` 配白字约 3.74:1，不足 4.5:1；青绿主题 CTA 改用 `#0F766E`（约 5.47:1）。
- 深色主题的 `accent #5B8CFF` 配白字约 3.16:1，不足 4.5:1；改用 `#11141A` 深色前景（约 5.83:1）。
- 暖纸深色的 `comment #8C7667` 约 3.97:1；改用 `#9C8775`（约 4.97:1）。

## 交付前检查

- [ ] 正文 ≥ 4.5:1，控件/图标 ≥ 3:1。
- [ ] 浅色主题至少 3 层表面，深色主题至少 4 层。
- [ ] 强调色只用于 CTA、选中、搜索命中、关键状态。
- [ ] 语法高亮在深浅主题都 ≥ 4.5:1。
- [ ] 图标在 16/32/128px、浅底/深底都能辨认。
- [ ] 主题不改变编码、换行、保存策略和正文。
