# 轻阅 0.14.0 Markdown Productivity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 交付本地 Markdown 的层次参考线、表格编辑和截图/选图/拖图闭环。

**Architecture:** Core 负责纯文本表格转换，WPF 层应用单次撤销命令。列表容器在 ReadingModel 与 MarkdownPreview 统一；图片附件经独立写入器生成相对链接，MainWindow 负责快照、生命周期和菜单路由。

**Tech Stack:** .NET 10、WPF、现有独立检查程序、PowerShell 7、NSIS。

**Spec:** `docs/superpowers/specs/2026-11-17-qingyue-0.14.0-markdown-productivity.md`

## Global Constraints

- Windows / .NET 10 / WPF，Core 不增加第三方依赖。
- 文件仍为标准 Markdown；所有正文修改进入既有撤销、安全保存、草稿、外部修改保护链路。
- 保留中文组合输入、源码 UTF-16 坐标、原生选区和撤销。非 Markdown 编辑、Mac 工程不作功能变更。
- 保持本地处理，不加入云同步、账号、历史迁移。
- 继续在用户指定的干净 `feat/windows-client` 工作区实施，不另外复制项目。
