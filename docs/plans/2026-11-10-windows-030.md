# Windows 0.3.0 阅读与分享升级

用户已确认执行全部七项提升并开新版本。基线 `e6cace3`；沿用原生 WPF/.NET 10。

## 范围与验收

1. 打开阶段进度、取消；Markdown 纯模型后台解析，WPF 内容分批生成。
   取消保留已打开内容；未复现的历史卡死不宣称已修复。
2. 关闭会话恢复时保留未加载草稿；退出等待冻结正文并在失败/取消后恢复；
   改名中断保留可恢复副本，排除路径随成功改名迁移。
3. 富文本、纯文本、Markdown 复制入口；当前代码块/表格复制；
   图片复制准备有界等待与取消，遗漏明确提示。
4. 保存实际阅读视口；编辑/预览保持段落，搜索退出恢复原阅读位置；
   目录跟随当前阅读章节并支持返回跳转前位置。
5. 图片原生放大/缩放/适应/复制；表格对齐与单元格样式，
   宽表格提供独立展开横向阅读，保留主文档真正 Table 及复制结构。
6. 修复段落映射重复大字符串哈希与图片占位构造放大，
   未变内容复用，切换过期加载取消，维持既有资源预算。
7. 导出带内嵌图的自包含 HTML，原子写入，禁止覆盖已打开的原文。
   更新版本、帮助、变更说明、安装包与 ZIP；验证升级保留资料。

## 修改与分工

- 主控：MainWindow.xaml/.xaml.cs/.Reading.cs/.Search.cs/.Commands.cs、
  新 Operations/Navigation partial、EditorTab、DocumentTypes、版本与发布脚本。
- 草稿：MainWindow.Persistence.cs、MainWindow.Recovery.cs、WorkspaceStore.cs、
  独立 RecoveryTests。
- 图表与性能：ReadingRenderer.cs、MarkdownPreview.cs、RichDocumentMap.cs、
  独立 ReaderExperienceTests 及图片/表格窗口。
- 分享：ReadingClipboard.cs、MainWindow.Clipboard.cs、HTML 导出辅助、
  ClipboardTests。

各模块先记录缺失行为/失败场景，再实现并定向验证。主控审查集成，运行统一回归，
独立隔离资料进行真实窗口验收，最后打包核对；本机替换不得强杀未保存窗口。

## 兼容与边界

- 不改 Mac、EnvDock、业务原件；不引入浏览器、NuGet 或网络图片请求。
- 继续支持原有快捷键、文件关联、编码、安全保存、50 万正文和图片资源预算。
- 新会话字段使用可缺省属性，旧会话可读取；不主动覆盖原文。
- 真实业务正文、图片、文件名、路径、哈希和诊断日志不入 Git。
- 腾讯文档等目标应用实际接收效果需用合成文档单独验证，不能用内存断言代替。
