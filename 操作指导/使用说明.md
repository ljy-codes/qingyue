# 轻阅 · 使用说明

版本：0.1.0 本机体验版。适用于 Intel Mac、macOS 13 或更高版本。

轻阅用于阅读和修改本机文本文件，采用 Mac 原生界面与文本组件。支持 TXT、JSON/JSONC、YAML、Markdown、INI/CONF/CONFIG 等文件。日常读写可以离线完成。

## 打开与编辑

1. 双击 `交付产品/轻阅.app` 启动。
2. 使用“打开”选择文本文件，或把文件拖入窗口。
3. 多个文件显示为标签，点击标签切换。
4. 修改完成后按 `⌘S` 保存；使用“另存为”另存一份。

新建文件可按 `⌘N`，打开文件可按 `⌘O`，另存为可按 `⌘⇧S`，关闭当前标签可按 `⌘W`。修改过的标签会显示圆点。查找使用 `⌘F`，撤销使用 `⌘Z`，跳转到行使用 `⌘L`。其他快捷键以应用菜单显示为准。

查找支持普通文本与正则表达式，可选择区分大小写、全词匹配；显示匹配计数并高亮前 3000 处。正则替换使用 `$1` 等捕获组，普通文本模式中的 `$` 与反斜线保持字面含义。正则有约 0.35 秒时间预算，耗时过长会中止；搜索最多处理 500 万个 UTF-16 单元，最多 10 万处匹配。多于 1000 处的全部替换会先确认，可用一次撤销恢复。左侧“最近打开”可再次打开原文件，侧栏可以收起。

## 阅读与外观

工具栏提供阅读模式、自动换行、字号和明暗主题控制。`A−`、`A+` 调整字号；“设置”可调整字号、行号和自动换行，并选择 TXT 阅读字体与行距。编辑模式使用等宽字体，可显示行号，阅读模式采用适合中文阅读的排版并隐藏行号。

阅读模式只读，点击“返回编辑”继续修改。使用查找或标题跳转时会返回编辑模式。底部状态栏显示保存状态、文件路径和光标位置，右侧菜单用于选择保存编码与换行符。

配色参考有序连点器：深蓝灰背景与蓝色强调，也可切换明亮模式。

## 格式支持

| 格式 | 当前能力 |
| --- | --- |
| TXT | 阅读、编辑、查找替换、编码与换行设置 |
| JSON | 基础高亮、语法检查、手动格式化 |
| JSONC | 基础高亮与语法检查，支持注释和尾逗号；当前不提供 JSONC 格式化 |
| YAML | 基础高亮，提示缩进中使用了 Tab；不提供完整 YAML 语法验证或自动格式化 |
| INI / CONF / CONFIG | 文本编辑、常见语法高亮、手动选择文件类型 |
| Markdown | 源码编辑、标题目录、原生轻量阅读；支持基本标题、列表、任务、引用、代码、文字链接及基础表格 |

`.config` 扩展名不能唯一确定文件语法，必要时从正文上方菜单手动选择类型。JSON 的“整理 JSON”需要完整有效的标准 JSON，数字原始写法会保留；JSONC、YAML 等类型不能使用此操作。

Markdown 当前不是完整的浏览器排版：脚注、复杂嵌套等高级语法可能保留源码样式；支持基础表格、任务列表、删除线和分隔线；表格上限为 32 列、1024 单元格，超出部分保留源码。图片仅显示文字占位，不显示本地或远程图片。阅读视图不会执行 HTML 或脚本，不会自动联网下载资源。点击网页链接会交给系统浏览器打开。

## 保存与恢复

- 文件保存由你决定，默认不会边输入边覆盖原文件。
- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030。原文件编码与换行会随文件保留；改变底部选项将在下次保存时转换文件。
- 若文件打开后乱码，请使用“文件 → 按编码重新打开”，不要用底部保存编码菜单代替重新解码。编码自动识别无法保证每个文件都正确。
- 文件含混合换行且被编辑后，保存时需要明确选择统一为 LF 或 CRLF；取消不会写回原文件。
- 文件被其他程序修改时，会提示处理冲突，避免静默覆盖。
- 编辑停止约 2 秒后会更新本机恢复草稿。异常退出后重新启动可恢复已记录的未保存内容；最后两秒内的输入不保证被记录。草稿不会替代你明确保存的原文件，也不会恢复所有已保存文件的标签会话。
- 关闭有修改的文件时，请根据提示保存、放弃或取消。

正常退出并完成保存或选择“不保存”后，恢复草稿会清除。草稿可能包含配置里的密码等内容，请按普通本机文档保护。

## 体验版范围

这是用于验证阅读、编辑体验和资源占用的原型：

- 单文件最多打开约 50 MB 文本，超过上限会拒绝打开，原文件不受影响。
- 文本长度超过 200,000 个 UTF-16 单元时，暂停语法高亮、实时检查和 Markdown 排版，保留基本文本编辑与只读阅读。中文常用字通常占一个单元，部分 Emoji 等占两个或更多单元。
- 大文件、超长单行和大量标签仍可能增加内存与排版耗时，当前不用于超大日志分析。
- Office 文档、云同步、插件和高级 Markdown 排版不在本版本范围内。

当前应用使用本机 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；适合本机体验，后续对外分发需补充正式签名流程。

可在 `开发空间/Samples` 中找到 Markdown、JSON、YAML 和配置示例。

## 编辑与位置记忆

Tab 在无选区时插入两个空格；选中文字后按 Tab 对涉及的整行缩进，Shift+Tab 取消缩进。换行继承当前行的前导空白。

关闭或切换文件时记录光标和阅读位置，下次打开同一路径的文件时恢复；不会因此自动打开整套标签会话，也不会自动保存原文件正文。

多硬链接文件为避免破坏链接关系，需要另存到新文件。原文件的访问权限、ACL 与扩展属性在可保留时随安全保存保留；权限不足会明确报错并保留编辑内容。
