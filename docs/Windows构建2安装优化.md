## 进度控件与口径

- `1006`：保留 NSIS 当前操作/文件文字。
- `1102`：新静态文字，格式为 `42% · 正在解压并写入程序文件`。
- `1103`：新 `msctls_progress32`，范围 0–100，安装时显示。
- `1004`：原 NSIS 指令进度，安装时隐藏；卸载时继续使用。自定义条默认隐藏，避免覆盖卸载进度。
- 校验阶段为 0%；每个文件成功写入后更新 `floor(95 × 累计字节 / 全部载荷字节)`；写入卸载入口为 96%，登记应用与快捷方式为 98%，全部成功才到 100%。
- 这是已完成工作量，不是剩余时间预测。解压一个大文件时可能暂时停留在同一百分比；没有按秒假涨的进度。失败保留最后百分比并显示失败阶段。
- 路径页的安全预检查发生在切换进度页之前；安装 section 再次校验目录与占用，防止页面间状态改变。

2026-11-09 已编译成功的中间测试包为 451,059 字节、5 文件载荷、808,345 字节，文件版本 0.2.0.2，压缩模式 Solid8。它用于安全逻辑回归，内部 WPF 载荷取自旧发布目录，并非新版交付包。当前打开的测试向导也是该中间包。之后源码默认压缩模式已选回 Solid32，并补充了卸载页默认文案/自定义进度条初始隐藏资源配置；当前已打开窗口不会热更新。父代理统一重新构建并验收 GUI。

结论与限制：

1. 删除 12 种非保留语言的 144 个卫星文件，载荷从 146,872,087 降至 138,790,087 字节，减少 **8,082,000 字节 / 5.50%**。zh-Hans 12 文件、606,928 字节保留；英文使用未删除的中性资源回退（旧载荷没有单独 en 目录）。全部根目录运行时/WPF/本机 DLL 保留。
2. 同为 Solid32，纯解压包减少 **931,600 字节 / 2.11%**。解压中位数 5.399 → 5.423 秒（增加 0.024 秒），**未测得安装提速**，不能把包体优化说成已解决全部安装耗时。
3. Solid8 在精简载荷上快 0.149 秒，但包大 573,956 字节；旧载荷上反而更慢。证据不足以承诺提速，默认保留 Solid32。
4. Zlib 在精简载荷上明显更快，但包比 Solid32 大 16,305,829 字节 / 37.65%，不符合本轮包体诉求，因此仅保留为可测参数。逐文件 LZMA 在基线中更大且更慢，不采用。
5. 这些是无主题、安全检查、卸载器、注册和快捷方式的纯解压包；**不能直接拿 43,307,417 与历史正式包 44,583,506 做同口径降幅计算**。新正式包大小和端到端安装耗时须源码冻结后实测。
6. 计时为同一机器的顺序热缓存运行，含进程启动、CRC 和实际文件解压写入，不含后续哈希/清理；没有冷启动/机械盘/杀毒排除测试。期间存在并行开发负载，编译耗时有波动；不据此推断精简后编译变慢。
7. 运行时/WPF 主文件占原发布目录约 94%，当前自包含/离线约束决定了进一步减包空间有限。不通过盲删运行时或不支持的 WPF trimming 冒险减包。

## 兼容性、失败恢复与风险

- 安装身份、注册项、用户资料位置、快捷方式入口、静默安装/卸载接口保持兼容；卸载静默路径始终保留资料。安全插件与卸载删除宏未改，危险路径/联接/运行占用/文件占用/降级/迁移保护已有回归。
- 安装按清单写入，失败返回非零并允许处理权限/占用后重试；未增加“自动杀程序”或绕过安全检查。安装中途断电/写盘失败仍可能留下部分程序文件，现有方案没有完整事务回滚，不能宣称原子升级。
- 语言精简只保证全新包中不带多余卫星语言。旧安装已有但新清单未列出的语言文件继续保留，避免删除未知文件；因此老目录升级后的占用可能大于全新安装，新卸载器也会保留这些清单外旧资源目录。没有为省空间新增广域递归删除。
