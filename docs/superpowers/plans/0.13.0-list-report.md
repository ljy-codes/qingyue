# Qingyue 0.13.0 Task 1 嵌套列表报告

日期：2026-11-16。工作目录：`D:\专用工具\阅读器\qingyue`。

## 结果

已实现两空格、四空格、Tab 的真实父子列表，`ReadingBlock.Level` 为零起点。层级来自实际祖先缩进栈，四空格不会凭空多出一层；Tab 按四列制表位计算。

续段以 `ListContinuation = true` 归属最近满足正文缩进的父项，包括从孙项逐级退回子项、父项的连续续段。有序、任务、无序列表可以混合，嵌套代码块归属父项。围栏内的列表语法、引用定义和图片语法保持代码内容。

预览使用真正的 `ListItem.Blocks` 嵌套 WPF List，阅读沿用同一渲染链。无序标记按深度循环使用 Disc / Circle / **Box**。第三层采用 Box 是根据本机 WPF 实测：Square 渲染为空心方框，Box 渲染为实心小方块；没有使用未取到正文的网络文档作为语义证据。

0 起点有序项保留字面前缀；非连续编号建立对应 StartIndex 的列表，后续连续编号复用原生列表。复制直接复用已有递归导出，HTML 保留真实父子结构与父级续段，部分子项复制排除未选中的正文。

- ReadingBlock 保持原构造签名，仅增加默认 false 的 init 属性；非 Markdown 路径保持原行为。

- 覆盖两/四空格与 Tab 三层列表、`10.` 四空格正文缩进、任务项、有序续段、父级续段以及独立四空格 marker 样式文本不成为列表。
- 对上述输入同时断言 reader 与 MarkdownEditing.ListMarkers 的层级、源文起点，以及预览 marker grammar。
- 原生列表选区文本可能包含自动生成的 marker；复制测试分别检查 HTML 正文排除范围及复制前后选区/pointer 不变。

## 已知限制与集成注意

- 延续现有轻量 Markdown parser，本任务未扩展为完整 CommonMark；列表内部嵌套标题、引用、表格等复杂块语法未作完整实现。
- 原有有序 marker 限制仍为 1–9 位数字；更长数字按普通文本处理。0 编号保留原字面 marker，正数使用 WPF 原生有序标记。
- 源文与可见文本映射仍是块内插值，不是任意字符级精确映射；这与既有接口一致。
- 原审查发现的 lazy continuation 差异已由主线程修复：编辑层保留无空行续行的列表上下文，并在结构移动时携带后续子项。已加入 `Markdown续段后列表标记与阅读层级一致` 和 `Markdown父项移动携带lazy续行及其后代` 回归；后续限定复核又修复两项段落边界，Core 编辑测试为 46/46。原始发现及红绿测试见 `0.13.0-editing-review.md`。
- Box 的实心效果已在本机上述字体和字号下验证，未穷举其他系统字体、DPI 和主题。ReadingTests 包含真实窗口回归；本任务没有另外完成整版输入法和全部 GUI 交互验收。
