# Mac 构建 8 验收

日期：2026-11-20。产品版本保持 **0.1.0**，构建编号 **8**。Windows 当前对齐基线为 `0869803`（`v0.18.0`），本轮合入此前尚未提交的 Mac 功能，并核查 0.1–0.18 的累积功能。

## 实际交付

- 0.15–0.18：四款同源图标（天空蓝、樱花紫、薄荷珊瑚、蜜桃紫）、深/浅/暖纸主题、阅读段距、紧凑合并顶栏和当前块/列表层级提示。
- 阅读资源：非活动标签取消图片任务并释放阅读树，返回时按需重建；离开预览清理隐藏文本；PNG 解码结果使用进程内有界缓存。保留撤销与源码，不声称达到 Windows 的相同 RSS 数值。
- 原生工作区文件树：后台扫描、文件名/类型过滤、收藏目录、双击打开。全局搜索窗口提供大小写/全词/正则/文件名选项、上下文、源行列定位、替换预览与确认应用；读写复用既有编码/BOM/换行/磁盘冲突保护。已打开文件由主编辑器处理。
- 阅读清单窗口：固定、已读/未读、移除、百分比和源位置恢复；书签可添加/移除和跳转。本机 JSON 原子保存、损坏隔离与权限限制。
- 批注窗口：摘录、备注/标签/五色编辑、删除、原文跳转、引文锚点准确/跟随/待核对/缺失状态，以及与搜索独立的下划线高亮。Markdown/HTML 简报禁止覆盖已打开原文。
- Markdown：列表续项/空项退出/升降级/任务，表格 Tab/Shift+Tab/Enter/行列/对齐/TSV，自动与参考链接，离线 Mermaid 时序图及流程图。表格/列表处理 UTF-16 和代码区保护，保持文件为标准 Markdown。
- 图片附件：读前字节/像素预算，拒绝附件目录符号链接，独占新建唯一 PNG，转义相对链接；失败或未接纳的插入清理本次附件。
- 手动更新只识别 Mac 发布标签；不会把 Windows 版本作为 Mac 更新，不静默安装。

## 边界仍明确记录

当前不是全部 Windows 行为已验证一致：工作区/清单/批注采用独立原生窗口，尚未合并为同款主侧栏；复杂嵌套列表/引用/表格层次、源码圆点/缩进参考线、双向滚动定位、图片视口优先调度和启动节流更新仍需继续对齐。完整状态见 [0.1–0.18 功能表](Mac-Windows功能对照-v0.18.md)。

构建目标为 Intel macOS 13+、ad-hoc 签名；Apple Silicon、Developer ID 公证、第三方 Office/腾讯文档粘贴未做本轮全量实机验收。WPF 软件渲染选项只解决 Windows 的驱动路径，Mac 不增加无效开关。
