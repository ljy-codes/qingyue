# 轻阅 0.12.0「阅读成果闭环」实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Windows 客户端完成选中高亮、摘录与备注、当前文档批注侧栏、跳回原文、Markdown/HTML 阅读简报导出，以及字体、行高、段距、深色/浅色/暖纸主题预设的完整阅读成果闭环。

**Architecture:** 批注作为本机附属数据独立保存到 `Annotations.json`，不修改原文；Core 负责数据校验、可见文本锚点修复和无 UI 的阅读简报生成，Windows 层负责 WPF 侧栏、备注编辑、独立 Adorner 高亮和文件导出。所有存储与导出沿用“临时文件写完再替换”的原子发布方式，旧设置和旧调用签名保留兼容重载。

**Tech Stack:** .NET 10、WPF、C# 14、`System.Text.Json`、`FlowDocument` / `Adorner`、无第三方 NuGet 的自研控制台测试。

**Spec:** 用户提供的 2026-11-16「建议的版本顺序 · 0.12.0：阅读成果闭环」截图；本文件「产品规格」为自包含执行规格。

## Global Constraints

- 只支持本机附属数据，不默认修改原文，不引入账号、云同步、WebView、脚本运行时或第三方包。
- 0.12.0 只覆盖“当前文档批注”和“当前文档阅读简报”，不做全资料库批量导出。
- 批注保存在数据目录的 `Annotations.json`，不改造 `Bookmarks.json`。
- `Annotations.json` 最多 5000 条、最大 64 MiB；引文最多 4000 字符；备注最多 4000 字符；上下文前后各最多 160 字符；标签最多 10 个且每个最多 32 字符。
- 阅读视图中的 `Quote` 必须是用户实际看到的可见文本；Markdown 偏移只作为定位提示，锚点修复必须在 `ReadingModel.VisibleText` 中核对引文。
- 外部文件变化或本地编辑后不能静默删除批注；无法唯一确认时保留原数据并标记 `Uncertain` 或 `Missing`。
- 批注高亮只能使用独立 `AnnotationHighlightAdorner`，不得复用、覆盖或清理搜索高亮状态。
- HTML 阅读简报必须对全部用户文本执行 `WebUtility.HtmlEncode`，并写入 CSP：`default-src 'none'; img-src data:; style-src 'unsafe-inline'; base-uri 'none'; form-action 'none'`。
- 导出不得覆盖当前原文、不得写到网络盘、不得经过符号链接或目录联接、不得写入 Windows 附加数据流。
- `ReaderSettings` 新字段必须有默认值，缺失时旧 `Settings.json` 可正常加载；`Theme` 缺失时按旧 `Dark` 值回退到深色或浅色。
- `ReadingRenderer` 与 `MarkdownPreview` 的旧公开方法签名必须保留；新能力通过重载加入。
- 阅读外观更新必须复用现有 `UpdatePresentation` 的原地重排能力，保留 `FlowDocument`、选区、图片和滚动位置。
- 所有新增测试先失败，再写最小实现；任务完成时提交独立 commit。
- 所有 PowerShell 命令使用 `pwsh -NoProfile`，不通过 WSL 执行仓库脚本。

## 产品规格

### 0.12.0 用户可见能力

1. 用户在阅读视图选中文本后点击“摘录”，可填写备注、标签和颜色；编辑视图中的选区也可摘录。
2. 阅读视图用颜色高亮当前文档已有批注；搜索高亮存在时两种高亮同时可见。
3. 左侧新增“批注”标签，显示引文、备注摘要、标签、位置和锚点状态；支持双击跳转、编辑和删除。
4. 跳转到批注时复用现有返回位置能力，用户可用 `Alt+←` 回到跳转前的位置。
5. 当前文档可导出 Markdown 或 HTML 阅读简报；简报包含标题、来源、生成时间、阅读进度、章节分组、引文、备注、标签和定位状态。
6. 阅读外观可设置字体、行高、段距和主题；主题固定为深色、浅色、暖纸，字号继续使用现有 `FontSize` 与 `A−` / `A+`。

### 锚点状态文案

| 状态 | 侧栏文案 | 是否绘制高亮 |
| --- | --- | --- |
| `Exact` | 位置准确 | 是 |
| `Shifted` | 已自动跟随正文移动 | 是 |
| `Uncertain` | 位置可能已变化，请双击核对 | 否 |
| `Missing` | 原文中未找到这段引文 | 否 |

- [ ] **Step 4: 写最小 `AnnotationStore`**

Create `AnnotationStore.cs`。使用与 `BookmarkStore` 相同的锁、临时文件、隔离和 Unicode JSON 策略：

```csharp
using System.Text.Encodings.Web;
using System.Text.Json;
using System.Text.Unicode;

namespace Qingyue.Core;

public sealed class AnnotationStore
{
    private const int MaximumItems = 5000;
    private const int MaximumQuoteLength = 4000;
    private const int MaximumNoteLength = 4000;
    private const int MaximumContextLength = 160;
    private const int MaximumTags = 10;
    private const int MaximumTagLength = 32;
    private const long MaximumBytes = 64L * 1024 * 1024;
    private static readonly JsonSerializerOptions JsonOptions = new()
    {
        Encoder = JavaScriptEncoder.Create(UnicodeRanges.All),
        WriteIndented = false
    };
    private readonly string root;
    private readonly string path;
    private readonly object gate = new();
    private List<DocumentAnnotation> items = [];

    public AnnotationStore(string root)
    {
        if (string.IsNullOrWhiteSpace(root)) throw new ArgumentException("批注目录不能为空。", nameof(root));
        this.root = Path.GetFullPath(root);
        path = Path.Combine(this.root, "Annotations.json");
    }

    public IReadOnlyList<DocumentAnnotation> Items
    {
        get { lock (gate) return items.ToArray(); }
    }

    public string? LastWarning { get; private set; }

    public async Task LoadAsync()
    {
        var loaded = await Task.Run(Read).ConfigureAwait(false);
        lock (gate)
        {
            items = loaded.Items;
            LastWarning = loaded.Warning;
        }
    }

    public IReadOnlyList<DocumentAnnotation> For(DocumentFile file)
    {
        ArgumentNullException.ThrowIfNull(file);
        string? currentPath = NormalizePath(file.Path);
        lock (gate)
        {
            return items.Where(item => currentPath is not null
                    ? string.Equals(NormalizePath(item.Path), currentPath, StringComparison.OrdinalIgnoreCase)
                    : item.DocumentId == file.Id && item.Path is null)
                .OrderBy(item => item.SourceStart)
                .ThenBy(item => item.CreatedAt)
                .ToArray();
        }
    }

    public DocumentAnnotation Add(DocumentFile file, AnnotationDraft draft)
    {
        ArgumentNullException.ThrowIfNull(file);
        ArgumentNullException.ThrowIfNull(draft);
        if (draft.DocumentId != file.Id)
            throw new ArgumentException("批注草稿不属于当前文档。", nameof(draft));
        if (draft.SourceStart < 0 || draft.SourceEnd < draft.SourceStart
            || draft.SourceEnd > file.Text.Length)
            throw new ArgumentOutOfRangeException(nameof(draft), "批注源位置超出当前文档。");
        ValidateText(draft.Quote, MaximumQuoteLength, "引文", allowEmpty: false);
        ValidateText(draft.ContextBefore, MaximumContextLength, "前置上下文", allowEmpty: true);
        ValidateText(draft.ContextAfter, MaximumContextLength, "后置上下文", allowEmpty: true);
        var now = DateTimeOffset.UtcNow;
        var item = new DocumentAnnotation(
            Guid.NewGuid(), file.Id, NormalizePath(file.Path),
            draft.SourceStart, draft.SourceEnd, draft.Quote,
            draft.ContextBefore, draft.ContextAfter, null, [], AnnotationColor.Amber,
            now, now, AnnotationAnchorState.Exact);
        lock (gate)
        {
            if (items.Count >= MaximumItems)
                throw new InvalidOperationException("批注数量已达到 5000 条上限。");
            items.Add(item);
        }
        return item;
    }

    public bool Update(Guid id, string? note, IReadOnlyList<string> tags, AnnotationColor color)
    {
        string? normalizedNote = string.IsNullOrWhiteSpace(note) ? null : note.Trim();
        if (normalizedNote is { Length: > MaximumNoteLength })
            throw new ArgumentException("备注超过 4000 字符。", nameof(note));
        string[] normalizedTags = (tags ?? []).Select(tag => tag.Trim())
            .Where(tag => tag.Length > 0).Distinct(StringComparer.OrdinalIgnoreCase).ToArray();
        if (normalizedTags.Length > MaximumTags || normalizedTags.Any(tag => tag.Length > MaximumTagLength))
            throw new ArgumentException("标签最多 10 个，每个最多 32 字符。", nameof(tags));
        if (!Enum.IsDefined(color)) throw new ArgumentOutOfRangeException(nameof(color));
        lock (gate)
        {
            int index = items.FindIndex(item => item.Id == id);
            if (index < 0) return false;
            items[index] = items[index] with
            {
                Note = normalizedNote, Tags = normalizedTags, Color = color,
                UpdatedAt = DateTimeOffset.UtcNow
            };
            return true;
        }
    }

    public bool Remove(Guid id)
    {
        lock (gate) return items.RemoveAll(item => item.Id == id) > 0;
    }

    public int MigratePath(Guid documentId, string? oldPath, string newPath)
    {
        string target = NormalizePath(newPath)
            ?? throw new ArgumentException("批注新路径不能为空。", nameof(newPath));
        string? source = NormalizePath(oldPath);
        int changed = 0;
        lock (gate)
        {
            for (int i = 0; i < items.Count; i++)
            {
                var item = items[i];
                bool matches = item.DocumentId == documentId
                    && (source is null ? item.Path is null
                        : string.Equals(NormalizePath(item.Path), source, StringComparison.OrdinalIgnoreCase));
                if (!matches) continue;
                items[i] = item with { Path = target, UpdatedAt = DateTimeOffset.UtcNow };
                changed++;
            }
        }
        return changed;
    }

    public int ApplyAnchorRepairs(IReadOnlyList<AnnotationAnchorRepair> repairs, DateTimeOffset repairedAt)
    {
        ArgumentNullException.ThrowIfNull(repairs);
        var byId = repairs.GroupBy(repair => repair.Id).ToDictionary(group => group.Key, group => group.Last());
        int changed = 0;
        lock (gate)
        {
            for (int i = 0; i < items.Count; i++)
            {
                if (!byId.TryGetValue(items[i].Id, out var repair)) continue;
                if (repair.SourceStart < 0 || repair.SourceEnd < repair.SourceStart)
                    throw new InvalidDataException("锚点修复范围无效。");
                if (!Enum.IsDefined(repair.AnchorState))
                    throw new InvalidDataException("锚点状态无效。");
                items[i] = items[i] with
                {
                    SourceStart = repair.SourceStart,
                    SourceEnd = repair.SourceEnd,
                    AnchorState = repair.AnchorState,
                    UpdatedAt = repairedAt
                };
                changed++;
            }
        }
        return changed;
    }

    public Task<AnnotationSaveResult> SaveAsync()
    {
        DocumentAnnotation[] snapshot;
        lock (gate) snapshot = items.ToArray();
        return Task.Run(() => Save(snapshot));
    }

    private AnnotationSaveResult Save(DocumentAnnotation[] snapshot)
    {
        var errors = new List<string>();
        string? temporary = null;
        try
        {
            Directory.CreateDirectory(root);
            byte[] bytes = JsonSerializer.SerializeToUtf8Bytes(snapshot, JsonOptions);
            if (bytes.LongLength > MaximumBytes) throw new InvalidDataException("批注文件超过 64 MiB 上限。");
            temporary = path + "." + Guid.NewGuid().ToString("N") + ".tmp";
            File.WriteAllBytes(temporary, bytes);
            File.Move(temporary, path, overwrite: true);
            temporary = null;
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException
            or JsonException or InvalidDataException)
        {
            errors.Add("批注保存失败：" + ex.Message);
        }
        finally
        {
            if (temporary is not null)
            {
                try { File.Delete(temporary); } catch { }
            }
        }
        return new AnnotationSaveResult(DateTimeOffset.UtcNow, errors);
    }

    private (List<DocumentAnnotation> Items, string? Warning) Read()
    {
        if (!File.Exists(path)) return ([], null);
        try
        {
            if (new FileInfo(path).Length > MaximumBytes)
                throw new InvalidDataException("批注文件超过 64 MiB 上限。");
            var loaded = JsonSerializer.Deserialize<List<DocumentAnnotation>>(File.ReadAllBytes(path), JsonOptions)
                ?? throw new InvalidDataException("批注文件为空。");
            if (loaded.Count > MaximumItems) loaded = loaded.Take(MaximumItems).ToList();
            foreach (var item in loaded) Validate(item);
            return (loaded.DistinctBy(item => item.Id).ToList(), null);
        }
        catch (Exception ex) when (ex is IOException or UnauthorizedAccessException
            or JsonException or InvalidDataException)
        {
            string? quarantine = null;
            try
            {
                quarantine = path + ".corrupt-" + Guid.NewGuid().ToString("N");
                File.Move(path, quarantine, overwrite: false);
            }
            catch { }
            return ([], "批注文件损坏，已忽略" + (quarantine is null ? "" : "并隔离") + "：" + ex.Message);
        }
    }

    private static void Validate(DocumentAnnotation item)
    {
        if (item.Id == Guid.Empty || item.DocumentId == Guid.Empty
            || item.SourceStart < 0 || item.SourceEnd < item.SourceStart
            || item.CreatedAt == default || item.UpdatedAt == default
            || !Enum.IsDefined(item.AnchorState) || !Enum.IsDefined(item.Color)
            || item.Path is not null && !Path.IsPathFullyQualified(item.Path))
            throw new InvalidDataException("批注字段无效。");
        ValidateText(item.Quote, MaximumQuoteLength, "引文", allowEmpty: false);
        ValidateText(item.ContextBefore, MaximumContextLength, "前置上下文", allowEmpty: true);
        ValidateText(item.ContextAfter, MaximumContextLength, "后置上下文", allowEmpty: true);
        if (item.Note is { Length: > MaximumNoteLength }) throw new InvalidDataException("批注备注过长。");
        if (item.Tags is null || item.Tags.Count > MaximumTags
            || item.Tags.Any(tag => tag is null || tag.Length is 0 or > MaximumTagLength))
            throw new InvalidDataException("批注标签无效。");
    }

    private static void ValidateText(string? value, int maximum, string name, bool allowEmpty)
    {
        if (value is null || value.Length > maximum || !allowEmpty && value.Length == 0)
            throw new ArgumentException($"{name}长度无效。", name);
    }

    private static string? NormalizePath(string? value) =>
        string.IsNullOrWhiteSpace(value) ? null : Path.GetFullPath(value);
}
```

```csharp
namespace Qingyue.Core;

public static class AnnotationAnchorResolver
{
    public static IReadOnlyList<DocumentAnnotation> Repair(
        string oldText, string newText, TextKind kind,
        IReadOnlyList<DocumentAnnotation> annotations, DateTimeOffset repairedAt)
    {
        ArgumentNullException.ThrowIfNull(oldText);
        ArgumentNullException.ThrowIfNull(newText);
        ArgumentNullException.ThrowIfNull(annotations);
        if (oldText == newText) return annotations.ToArray();
        var model = ReadingModel.Build(newText, kind);
        var results = new List<DocumentAnnotation>(annotations.Count);
        foreach (var item in annotations)
        {
            int start = Math.Clamp(TextAnchorMapper.Map(oldText, newText, item.SourceStart), 0, newText.Length);
            int end = Math.Clamp(TextAnchorMapper.Map(oldText, newText, item.SourceEnd), start, newText.Length);
            if (VisibleAt(model, start, end) == item.Quote)
            {
                results.Add(item with
                {
                    SourceStart = start,
                    SourceEnd = end,
                    AnchorState = start == item.SourceStart && end == item.SourceEnd
                        ? AnnotationAnchorState.Exact : AnnotationAnchorState.Shifted,
                    UpdatedAt = repairedAt
                });
                continue;
            }

            var matches = Occurrences(model.VisibleText, item.Quote);
            if (matches.Count > 1)
            {
                matches = matches.Where(match =>
                    model.VisibleText.AsSpan(0, match).EndsWith(item.ContextBefore) &&
                    model.VisibleText.AsSpan(match + item.Quote.Length).StartsWith(item.ContextAfter)).ToList();
            }
            if (matches.Count == 1)
            {
                int displayStart = matches[0];
                int sourceStart = model.DisplayToSource(displayStart);
                int sourceEnd = model.DisplayToSource(displayStart + item.Quote.Length);
                results.Add(item with
                {
                    SourceStart = sourceStart, SourceEnd = Math.Max(sourceStart, sourceEnd),
                    AnchorState = AnnotationAnchorState.Shifted, UpdatedAt = repairedAt
                });
            }
            else
            {
                results.Add(item with
                {
                    SourceStart = start, SourceEnd = end,
                    AnchorState = matches.Count == 0
                        ? AnnotationAnchorState.Missing : AnnotationAnchorState.Uncertain,
                    UpdatedAt = repairedAt
                });
            }
        }
        return results;
    }

    private static string VisibleAt(ReadingModel model, int sourceStart, int sourceEnd)
    {
        int start = model.SourceToDisplay(sourceStart);
        int end = model.SourceToDisplay(sourceEnd);
        if (end <= start && sourceEnd > sourceStart)
            end = Math.Min(model.VisibleText.Length, start + (sourceEnd - sourceStart));
        start = Math.Clamp(start, 0, model.VisibleText.Length);
        end = Math.Clamp(end, start, model.VisibleText.Length);
        return model.VisibleText[start..end];
    }

    private static List<int> Occurrences(string text, string quote)
    {
        var result = new List<int>(2);
        if (quote.Length == 0) return result;
        int cursor = 0;
        while (cursor <= text.Length - quote.Length)
        {
            int found = text.IndexOf(quote, cursor, StringComparison.Ordinal);
            if (found < 0) break;
            result.Add(found);
            if (result.Count == 2) break;
            cursor = found + Math.Max(1, quote.Length);
        }
        return result;
    }
}
```

```csharp
namespace Qingyue.Core;

public sealed record ReadingBriefInput(
    string Title,
    string? SourcePath,
    TextKind Kind,
    string SourceText,
    int ProgressPercent,

    IReadOnlyList<ReadingHeading> Headings,

public static class ReadingBriefExporter
{
    public const int MaximumBytes = 8 * 1024 * 1024;

    public static string BuildMarkdown(ReadingBriefInput input)
    {
        ArgumentNullException.ThrowIfNull(input);
        var builder = new StringBuilder();
        builder.Append("# 阅读简报：").AppendLine(EscapeInline(input.Title.Trim()));
        builder.AppendLine();
        builder.Append("- 来源：").AppendLine(input.SourcePath is null

        builder.Append("- 生成时间：").AppendLine(input.GeneratedAt.ToString("yyyy-MM-dd HH:mm zzz"));
        builder.Append("- 阅读进度：").Append(Math.Clamp(input.ProgressPercent, 0, 100)).AppendLine("%");
        builder.Append("- 批注数量：").AppendLine(input.Annotations.Count.ToString());
        foreach (var group in GroupByChapter(input))
        {
            builder.AppendLine().Append("## ").AppendLine(EscapeInline(group.Title));
            foreach (var item in group.Items)

                    .Append(" 行 · ").AppendLine(AnchorStateText(item.AnchorState));
                foreach (string line in item.Quote.ReplaceLineEndings("\n").Split('\n'))
                    builder.Append("> ").AppendLine(EscapeMarkdownUserText(line));
                if (!string.IsNullOrWhiteSpace(item.Note))
                {
                    builder.AppendLine().AppendLine("**备注**").AppendLine();
                    foreach (string line in item.Note.ReplaceLineEndings("\n").Split('\n'))
                        builder.Append("> ").AppendLine(EscapeMarkdownUserText(line));
                }
                if (item.Tags.Count > 0)
                    builder.AppendLine().Append("**标签** ").AppendLine(
                        string.Join(" ", item.Tags.Select(tag => "`" + tag.Replace("`", "\\`") + "`")));
            }
        }
        string result = builder.ToString();
        EnsureSize(result);
        return result;
    }

    public static string BuildHtml(ReadingBriefInput input)
    {
        ArgumentNullException.ThrowIfNull(input);
        string Encode(string value) => WebUtility.HtmlEncode(value);
        var builder = new StringBuilder();
        builder.AppendLine("<!DOCTYPE html>")
            .AppendLine("<html lang=\"zh-CN\"><head><meta charset=\"utf-8\">")

            .AppendLine("<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">")

            .AppendLine("</head><body>")
            .Append("<h1>阅读简报：").Append(Encode(input.Title)).AppendLine("</h1>")
            .Append("<p class=\"meta\">来源：").Append(input.SourcePath is null ? "未保存文档" : Encode(input.SourcePath))
            .Append("<br>生成时间：").Append(Encode(input.GeneratedAt.ToString("yyyy-MM-dd HH:mm zzz")))
            .Append("<br>阅读进度：").Append(Math.Clamp(input.ProgressPercent, 0, 100)).Append("%</p>");
        foreach (var group in GroupByChapter(input))
        {
            builder.Append("<h2>").Append(Encode(group.Title)).AppendLine("</h2>");

            {
                builder.Append("<article><p class=\"state\">第 ").Append(LineNumber(input.SourceText, item.SourceStart))
                    .Append(" 行 · ").Append(Encode(AnchorStateText(item.AnchorState))).AppendLine("</p>")
                    .Append("<blockquote>").Append(Encode(item.Quote).ReplaceLineEndings("<br>")).AppendLine("</blockquote>");
                if (!string.IsNullOrWhiteSpace(item.Note))
                    builder.Append("<p><strong>备注</strong><br>")
                        .Append(Encode(item.Note).ReplaceLineEndings("<br>")).AppendLine("</p>");
                if (item.Tags.Count > 0)
                    builder.Append("<p><strong>标签</strong> ")
                        .Append(string.Join(" ", item.Tags.Select(tag => "<code>" + Encode(tag) + "</code>")))
                        .AppendLine("</p>");
                builder.AppendLine("</article>");
            }
        }
        builder.AppendLine("</body></html>");
        string result = builder.ToString();
        EnsureSize(result);
        return result;
    }

    public static string AnchorStateText(AnnotationAnchorState state) => state switch
    {
        AnnotationAnchorState.Exact => "位置准确",
        AnnotationAnchorState.Shifted => "已自动跟随正文移动",
        AnnotationAnchorState.Uncertain => "位置可能已变化，请核对",
        AnnotationAnchorState.Missing => "原文中未找到这段引文",
        _ => "位置状态未知"
    };

    private static IReadOnlyList<(string Title, IReadOnlyList<DocumentAnnotation> Items)> GroupByChapter(
        ReadingBriefInput input)
    {
        var annotations = input.Annotations
            .OrderBy(item => item.SourceStart).ThenBy(item => item.CreatedAt).ToArray();
        var headings = input.Headings.OrderBy(item => item.SourceStart).ToArray();
        return annotations.GroupBy(item =>
        {
            var heading = headings.LastOrDefault(candidate => candidate.SourceStart <= item.SourceStart);
            return heading?.Title ?? "开篇";
        }).Select(group => (group.Key, (IReadOnlyList<DocumentAnnotation>)group.ToArray())).ToArray();
    }

    private static int LineNumber(string text, int offset)
    {
        int end = Math.Clamp(offset, 0, text.Length);
        int line = 1;
        for (int i = 0; i < end; i++) if (text[i] == '\n') line++;
        return line;
    }

    private static string EscapeInline(string value) =>
        value.Replace("\\", "\\\\").Replace("<", "&lt;").Replace(">", "&gt;")
            .Replace("#", "\\#").Replace("*", "\\*").Replace("_", "\\_")
            .Replace("[", "\\[").Replace("]", "\\]");

    private static string EscapeMarkdownUserText(string value) =>
        EscapeInline(value).Replace("`", "\\`");

    private static void EnsureSize(string value)
    {
        if (Encoding.UTF8.GetByteCount(value) > MaximumBytes)
            throw new InvalidOperationException("阅读简报超过 8 MiB 上限，请减少批注数量或备注长度。");
    }
```
