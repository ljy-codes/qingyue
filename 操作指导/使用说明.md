# 轻阅 · 使用说明

产品版本：**0.1.0**。本轮为 **Mac 构建 2**，适用于 Intel Mac、macOS 13 或更高版本。

轻阅用于阅读和修改本机文本文件，采用 Mac 原生界面与文本组件。支持 TXT、JSON/JSONC、YAML、Markdown、INI/CONF/CONFIG 等文本，日常读写可以离线完成。

## 打开与编辑

1. 双击已安装的 `/Applications/轻阅.app`，或运行项目中的 `交付产品/轻阅.app`。
2. 使用“打开”选择文本文件，或把文件拖入编辑区。
3. 多个文件显示为标签，点击标签或使用菜单提供的快捷键切换。
4. 修改后按 `⌘S` 保存；使用“另存为”另存一份。

常用快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 | `⌘N` / `⌘O` |
| 保存 / 另存为 | `⌘S` / `⌘⇧S` |
| 查找 / 关闭查找栏 | `⌘F` / `Esc` |
| 撤销 / 重做 | `⌘Z` / `⌘⇧Z` |
| 阅读 / 编辑模式 | `⌘R` |
| 文档目录 | `⌘⇧O` |
| 专注 / 退出专注 | `⌘⇧F` |
| 上一个 / 下一个标签 | `⌘⇧[` / `⌘⇧]` |
| 第 1–8 个标签 / 最后一个标签 | `⌘1`–`⌘8` / `⌘9` |
| 关闭当前标签 | `⌘W` |
| 跳转源文行号 | `⌘L` |
| 设置 | `⌘,` |

快捷键以应用菜单为准；输入法候选期间先遵循输入法的组合输入行为。跳转源文行号会进入编辑模式，文档目录则保持当前阅读或编辑模式。

标签右键菜单提供“关闭此标签”“关闭其他标签”“复制路径”和“在 Finder 中显示”。“文件”菜单也提供当前文件的复制路径与 Finder 入口。尚未保存的新文件没有可复制或显示的磁盘路径。

窗口会记住大小与位置。红叉关闭整个文档窗口，处理未保存内容后清空该窗口的标签，应用仍保持运行；从 Dock 重新打开时显示空白文档。`⌘W` 关闭当前标签，关闭最后一个标签时也关闭窗口。`⌘Q` 才退出应用。未保存内容应根据界面提示保存、取消或放弃。

文件类型处于自动识别时，新建或另存改变扩展名后会重新识别；用户手动选定的类型应保留。`.config` 扩展名不能唯一确定语法，必要时从文件类型菜单手动选择。

## 查找与替换

- 普通文本和正则表达式均支持，可选区分大小写、全词匹配。
- 显示匹配计数，并高亮前 3000 处匹配；Esc 关闭查找栏。
- 阅读模式内查找阅读视图的显示文字，保持阅读模式；隐藏的 Markdown 标记不作为可见正文匹配。
- 替换用于可编辑的源文。阅读页面是只读视图，先返回编辑再替换。
- 正则替换可使用 `$1` 等捕获组；普通模式中的 `$` 与反斜线保持字面含义。
- 搜索最多处理 500 万个 UTF-16 单元，最多 10 万处匹配。复杂正则有时间预算，耗时过长会中止；这不是所有设备均在固定毫秒内完成的承诺。
- 多于 1000 处的全部替换会先确认；全部替换可用一次撤销恢复。

全词按照 Unicode 字母、数字、组合标记与下划线的边界匹配，连续中文也会被视为连续文字。左侧“最近打开”可再次打开原文件，侧栏可以收起。

## 阅读与外观

每个文件可以保留自己的阅读或编辑模式。阅读模式只读，点击“返回编辑”继续修改；查找或目录导航会留在阅读视图中。

TXT/Markdown 侧重正文阅读，提供版心与专注布局，减少长行和工具栏干扰。JSON、YAML、INI 等结构化文本在阅读中保留原文、等宽缩进与高亮，避免正文比例字体影响结构辨认；阅读不会自动格式化或保存配置文件。

“设置”提供 10–30 的字号、正文阅读字体与行距、行号、自动换行和“外观跟随系统”。阅读版心可选“紧凑”“标准”“宽”“全宽”，窗口较小时会适应可用空间。配置阅读保持等宽字体，正文阅读字体不会替换配置的等宽显示。

专注布局隐藏侧栏、标签和多数工具栏操作，保留正文与退出专注入口；`⌘⇧F` 切换。查找栏打开时先按 Esc 关闭查找，再按 Esc 可退出专注。专注布局改变控件显隐，阅读/编辑模式改变展示与编辑行为，二者可以分别使用。

目录根据文档中可识别的标题和章节生成。Markdown 标题、TXT 常见章节可用于跳转；无法识别时目录可能为空。目录和源文/阅读切换使用块级对应，通常定位到同一标题、段落或代码/表格块，**不承诺任意字符选区都能精确互转**。

配色参考有序连点器：深蓝灰背景与蓝色强调，也可使用明亮外观或在设置中跟随系统。工具栏手动切换明暗会关闭“跟随系统”，可在设置中重新开启。

## 格式支持

| 格式 | 当前能力 |
| --- | --- |
| TXT | 阅读、编辑、查找替换、编码与换行设置、常见章节识别 |
| JSON | 等宽高亮、语法检查、手动格式化 |
| JSONC | 等宽高亮与语法检查，支持注释和尾逗号；当前不提供 JSONC 格式化 |
| YAML | 等宽高亮，提示缩进中的 Tab；没有完整 YAML 语法验证或自动格式化 |
| INI / CONF / CONFIG | 文本编辑、常见语法高亮、手动选择类型 |
| Markdown | 源码编辑、阅读内标题导航、原生轻量排版；基本标题、列表、任务、引用、代码、链接和表格 |

“整理 JSON”只用于完整有效的标准 JSON，数字原始写法会保留；JSONC、YAML 等不能使用此操作。没有完整解析和保真能力的格式不会自动重排保存。

Markdown 并非完整浏览器排版：脚注、复杂嵌套等高级语法可能保留源码样式；基础表格上限为 32 列、1024 单元格，超出部分保留源码。图片仅显示文字占位，不显示本地或远程图片。HTML 和脚本不会执行，也不会自动联网下载资源；点击网页链接会交给系统浏览器打开。

## 保存与恢复

- 默认不随输入覆盖原文件，写回由你明确保存。
- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030。保留原编码与换行，改变底部选项将在下次保存时转换；编码转换有确认。
- 打开后发现乱码时，使用“文件 → 按编码重新打开”，不要以保存编码菜单代替重新解码。自动编码识别无法保证每个文件都正确。
- 混合换行文件需要重新写入、又没有足够原始字节信息时，会要求明确统一为 LF 或 CRLF；取消不会写回原文件。构建 2 补上了恢复后/未缓存原始字节时明确覆盖的边界。
- 文件被外部修改时会提示处理冲突；当前编辑内容仍保留。冲突检测降低误覆盖风险，不代表与所有其他程序实现绝对事务隔离。
- 编辑停止约 2 秒后更新本机恢复草稿。异常退出后可恢复已记录的未保存内容；最后两秒内的输入不保证已记录。
- 草稿不替代原文件，也不等同于完整标签会话。已保存文件的标签会话不会因为草稿存在而全部恢复。
- 关闭有修改的文件时，按提示保存、保留或放弃。

正常退出并完成保存或选择放弃后会清理恢复草稿。草稿可能包含配置里的密码等内容，目前存放在本机应用支持目录，仍应按普通本机文档保护。

多硬链接文件需另存到新文件，避免原子替换静默拆开链接。保存尽力保留原访问权限、ACL 与扩展属性；权限不足时会报错并保留编辑内容。

## 缩进与位置记忆

Tab 在无选区时插入两个空格；选中文字后按 Tab 对涉及的整行缩进，Shift+Tab 取消缩进。换行继承当前行的前导空白。输入法候选期间的快捷键行为仍需按实际输入法验收。

关闭或切换文件时记录光标、内容位置与阅读模式，下次打开同一路径时尝试恢复。源文与阅读块的对应帮助模式切换和改字号/版心后定位，但文档被大幅修改后不保证仍落在完全相同的文字处。关闭窗口后再从 Dock 打开仍是空白文档，需再次打开原文件；这项位置记忆不会自动保存原文或恢复整套标签。

## 体验版边界

- 单文件上限 50 MiB；超出拒绝打开，原文件不受影响。
- 超过 200,000 个 UTF-16 单元时暂停高亮、实时检查和 Markdown 排版，保留基本编辑与只读阅读。中文常用字通常占一个单元，部分 Emoji 占两个或更多。
- 大文件、超长单行与大量标签可能增加内存和排版耗时，不适合超大日志分析。
- 图片、完整 Markdown、完整 YAML 校验、会话恢复、多窗口、文件夹全局搜索、Office、云同步和插件尚未实现。
- 当前只有 Intel Mac 包。Windows 需单独实现和实机验收；Apple Silicon 尚未交付原生 ARM 包。

当前采用 ad-hoc 本机签名，未做 Developer ID 签名或 Apple 公证。示例位于 `开发空间/Samples`；构建 2 使用独立预发布 `macos-build-2`，旧 `v0.1.0` 保留。安装更新前应先处理未保存内容并退出旧应用，再替换已安装副本。
