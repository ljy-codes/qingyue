## WIN-20261127-01：选区重复项联动提示

### 现象

双击选中一个文本片段时，如果同一文档上方或其他位置存在完全相同的片段，界面没有提示或联动标记。用户只能人工上下查找，容易漏看重复内容。

示例使用匿名数据：

```text
周一：
  1. ABC-12345 处理重复事项
周二：
  1. ABC-12345 处理重复事项
```

双击第二处 `12345` 后，第一处没有提示。

### 期望

- 自动识别当前文档中与选中片段相同的其他文本位置。
- 其他位置使用次级标记提示，帮助用户快速发现重复点。
- 当前双击选区保持主选中状态；`Ctrl+C`、右键复制和拖放复制仍只复制当前选中的那一处，不能复制全部重复项。
- 可显示重复次数或上一个/下一个重复位置入口，但不得改变用户当前选中的复制源。

### 验收标准

1. 同一文档内的完全相同片段能被识别，并在其他位置显示明确但不抢眼的提示。
2. 复制结果严格等于用户当前双击或拖选的内容。
3. 切换选区后提示立即更新，不保留过期标记。
4. 大量重复项或长文档下不能阻塞输入；需要防抖、数量上限和耗时上限。

### 待确认

- 匹配是否区分大小写、是否忽略首尾空白。
- 是否需要点击提示直接跳转到对应重复位置。
- macOS 现有版本是否已有同类交互；如有，以 macOS 的实际行为为验收基准。

## WIN-20261127-02：Markdown“复制全文（含图片）”失效

### 现象

在 Markdown 预览或分屏预览中点击“复制全文（含图片）”后，粘贴端没有得到任何内容，表现为复制动作没有生效。

### 复现步骤

1. 打开一份包含正文和图片的 Markdown 文档。
2. 进入 Markdown 预览或分屏预览。
3. 点击工具栏“复制全文（含图片）”。
4. 在记事本、Word 或其他富文本编辑器中粘贴。

### 当前结果

- 剪贴板没有可粘贴内容。
- 用户无法确认是复制失败、图片等待超时，还是内容超限。

### 期望

- 成功时，剪贴板包含富文本正文和已加载图片。
- 完成后显示明确状态，例如“已复制全文，含 N 张图片”。
- 图片未加载、超过资源上限或富文本降级时，必须明确提示降级原因，不能静默无结果。
- 失败时保留可诊断的错误信息，至少能区分“无内容”“等待图片超时”“序列化失败”“剪贴板写入失败”。

### 验收标准

1. 含普通正文、表格和本地图片的 Markdown 可以完整复制并粘贴到 Word 或微信等富文本目标。
2. 纯文本粘贴回退路径可用。
3. 复制成功或失败均有可见状态反馈。
4. 连续点击、切换标签和复制过程中文件被修改时，不会写入旧内容或空内容。

## WIN-20261127-03：Markdown 内嵌 HTML/SVG 图片未渲染

### 现象

Markdown 文档中包含 `<div>`、`<svg>`、`<rect>`、`<text>` 等内嵌 HTML/SVG 图形时，预览区显示大量源码或源码样式内容，看不到最终图形效果。

### 期望

- 对支持范围内的内嵌 SVG/HTML 图片进行安全渲染，显示最终图形而不是源码。
- 不执行脚本、事件处理器、外部网络请求或任意本地文件访问。
- 无法安全渲染时显示明确的图片占位和原因，而不是把整段标记当作普通正文展示。
- 图片应能随阅读内容参与复制和 HTML 导出的既有能力。

### 验收标准

1. 含本地图片和受支持内嵌 SVG 的 Markdown 在预览中直接显示图形。
2. 恶意脚本、外链资源和越界文件路径不会执行或加载。
3. 不支持的图形显示可理解的占位提示，并保留源码可编辑性。
4. 渲染结果与 macOS 最终行为一致。

### 待确认

- 反馈中的图形使用普通 HTML 片段还是围栏代码块；需要一份脱敏后的最小 Markdown 样本用于最终复现。
- 需要明确支持范围：内嵌 SVG、`<img>` 标签、Data URI，还是仅支持标准 Markdown 图片语法。
