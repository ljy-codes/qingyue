# Mac / Windows 功能对照

目标：两个平台的最终用户功能一致，分别使用 AppKit / WPF 原生实现。Mac 本轮验收参考[构建 14 记录](Mac构建14验收.md)；Windows 依据历史 0.18.0 源码及说明记录，本轮未复测。

| 功能契约 | Mac 0.4.0 | Windows 历史 0.18.0 | 后续验收要求 |
|---|---|---|---|
| 多标签、打开、编辑、保存、编码、换行、冲突处理 | 已有；Mac 自动回归通过 | 历史已实现，待 Windows 复测 | 两端真实文件保存与外部修改 |
| Markdown 阅读、分屏、目录与位置映射 | 已有；Mac 自动回归通过 | 历史已实现，待 Windows 复测 | 表格、源码范围、阅读位置 |
| 本地图片、截图插入、表格编辑、有限 Mermaid | 已有；有资源预算 | 历史已实现，预算可能不同 | 保留源文、超限降级、支持子集一致 |
| 查找替换、正则、UTF-16 位置 | 新增可取消和分块进度 | 历史路径，未移植本轮优化 | Windows 补相同行为和性能回归 |
| 工作区、全局搜索、阅读清单、书签、批注、简报 | 已有；独立原生窗口 | 历史已实现，主界面组织不同 | 功能一致，窗口组织可遵循平台规范 |
| 图文复制、纯文本和 HTML 导出 | 已有；Mac 自动回归通过 | 历史已实现，待 Windows 复测 | 目标软件粘贴结果分别验证 |
| 会话和独立恢复草稿 | 已有；Mac 自动回归通过 | 历史已实现，待 Windows 复测 | 损坏草稿、冲突、排除策略 |
| 外观主题、字体与四款图标 | 7 套主题，1024px 图标，独立滚动预览 | 历史外观实现，本轮未同步 | Windows 后续核对主题契约与可访问性 |
| 检查更新 | 按 Mac 平台标签查询 | 历史 Windows 更新路径 | 新平台标签分别验证，不串平台 |

完整 CommonMark/GFM、完整 YAML 校验、多窗口、Office 编辑、云同步、插件和自动安装更新尚无统一交付承诺，应另立方案和双平台验收门槛。
