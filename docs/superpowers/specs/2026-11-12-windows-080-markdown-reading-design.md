# 轻阅 Windows 0.8.0 Markdown 深度阅读与更新设计

## 版本定位

0.8.0 的第二条主线是“阅读有层次、搜索可定位、文件更新可判断”。Markdown 默认以阅读预览打开，用户在阅读时需要知道当前章节、快速跳转标题、搜索后看到所有匹配位置，并在原文件被其他程序修改时看到清晰提示。

本设计继续使用现有 WPF `FlowDocument` 和 `ReadingModel`。搜索、目录、外部更新和大文档性能都在现有模型上增量增强，不引入浏览器内核，也不把 Markdown 阅读改成左右分屏默认布局。

## 当前基线

当前版本已具备：

- Markdown 打开即预览，编辑时可切换原文；
- 50 万正文字符预览能力，内嵌图片数据单独计限；
- 标题、列表、引用、表格、代码和 Mermaid 的阅读样式；
- 目录列表和跳转位置恢复；
- 普通搜索、正则搜索、全词搜索、上一个/下一个和替换；
- 切换标签、激活窗口时检查外部文件变化；
- 外部变化发生时尝试保持编辑、阅读和 Markdown 分屏的锚点。

当前缺口：

1. 搜索后只选中当前匹配项，其他结果没有全量高亮；
2. 目录可以打开，但缺少固定、当前章节跟随和更清晰的层级信息；
3. 外部变化自动应用后提示有限，用户难以判断内容是否来自磁盘；
4. Markdown 预览中标题、引用、任务列表、代码块和表格仍需要更清晰的阅读层次；
5. 大文档需要统计渲染元素和图片控件，避免切换窗口尺寸时重复构建或内存增长。

## 目标

- Markdown 打开即进入全宽预览；进入编辑时恢复代码格式；分屏只是主动选择。
- 目录显示标题级别、当前章节，并支持固定/取消固定。
- 阅读滚动时目录当前项跟随；目录跳转保留返回位置。
- 搜索结果全部高亮，当前匹配使用更明显的样式，计数继续显示 `当前 / 总数`。
- 搜索结果在阅读预览和编辑原文中都能映射到真实文本，不改变原文。
- 外部文件变化时显示横幅或状态区提示，明确提供“重新加载”“保留当前内容”“查看差异”三个动作。
- 自动识别当前文件的磁盘版本；用户切换到标签或激活窗口后看到最新内容。
- 大于 50 万正文字符时继续安全降级；50 万以内的 Markdown 构建支持取消、批量让出 UI 线程和滚动位置保持。
- 代码块支持复制按钮/上下文菜单，并保留原始换行和语言名；表格、引用、任务列表具有稳定层级。

## 非目标

- 不做通用 Markdown 编辑器，不实现完整 CommonMark/GFM 解析器。
- 不支持跨文件语义索引、后台全盘搜索或网络图片。
- 不自动合并用户未保存内容与磁盘内容；冲突时保留当前编辑并允许用户查看差异。
- 不改变用户原文、编码、换行方式或会话数据结构。
- 不修改 Mac 工程。

## 用户可见行为

### 默认阅读与编辑

- 打开 `.md` 后直接使用阅读预览；
- 点击“编辑原文”进入单栏代码编辑；
- 点击“返回预览”回到单栏阅读；
- “分屏编辑”仍可手动开启，窗口缩放时编辑区与预览区使用 `GridSplitter` 约束，预览正文不会溢出窗口；
- 预览中显示标题层级、引用边框、任务列表状态、代码块语言标签、表格表头和图片说明。

### 目录

目录项保存标题文本、级别、源偏移和预览偏移。当前章节按阅读视口中最靠近顶部的标题更新。目录跳转前记录当前阅读位置，点击“返回位置”恢复。

目录固定时保留在侧栏，取消固定时允许侧栏恢复最近打开/书签内容。没有标题时显示“当前文档没有可用标题”。

### 搜索

搜索结果使用一组独立的 `TextRange`/装饰层：

- 全部匹配使用半透明高亮；
- 当前匹配使用强调色边框或更亮的背景；
- 搜索框输入、选项变化、切换标签和阅读/编辑模式时重建高亮；
- 关闭搜索时清除全部高亮，恢复原有选区和阅读位置；
- 匹配数量继续受 `SearchEngine` 上限保护。

高亮层不修改文档正文，不影响复制和保存。

### 外部更新

当当前文件在磁盘变化且当前标签没有未保存编辑时，显示：

> 文件已更新，轻阅已载入最新内容。

当当前标签存在未保存编辑时，显示：

> 文件已被外部修改，当前未保存内容已保留。

动作：

- “重新加载”：丢弃当前未保存文本，载入磁盘版本，并映射阅读位置；
- “保留当前内容”：关闭提示，不写盘；
- “查看差异”：打开只读差异窗口，左侧为当前内容，右侧为磁盘内容，限制在 200 万字符以内。

文件删除、暂时不可访问时只显示状态，不清空当前内容。

## 技术方案

### 1. 阅读目录

增加纯数据 `MarkdownOutlineEntry` 和 `MarkdownOutlineState`，放在 `Qingyue.Core`：

- `MarkdownOutlineEntry(int Level, string Title, int SourceStart, int SourceLength, int DisplayStart)`；
- `MarkdownOutline.Build(string text, ReadingModel model)`；
- `MarkdownOutlineState` 保存 `IsPinned` 和 `SelectedSourceStart`，不持久化正文。

Windows 侧由 `MainWindow.Navigation.cs` 负责选中跟随和跳转，`MainWindow.xaml` 增加固定按钮和当前章节提示。目录构建只使用 `ReadingModel.Blocks` 的标题块，不重复解析整篇文本。

### 2. 搜索高亮

增加 `SearchHighlightService`，职责是把 `SearchMatch` 转换为阅读预览或编辑器的可见高亮：

- 编辑器使用 `TextBoxBase.Selection` 仅给当前匹配，其他匹配通过 `Adorner` 绘制；
- 阅读预览使用 `Adorner` 绘制匹配矩形，当前项使用更强颜色；
- 高亮只绑定当前 `searchGeneration`，内容或模式变化即丢弃；
- 高亮计算失败时仍保留当前匹配选择和计数。

为避免 WPF 文档结构被修改，服务不插入 `Run`、不改变 `TextPointer` 映射，也不参与剪贴板导出。

### 3. 外部更新横幅与差异

在 `MainWindow.xaml` 的文档工具区域增加 `ExternalChangePanel`。`MainWindow.ExternalChanges.cs` 负责设置状态和动作，`ExternalFileRefresh` 继续负责 worker 线程读取和快照校验。

差异使用纯文本行级 LCS，增加 `TextDiff`：

- 输入上限 2,000,000 个 UTF-16 单元、行数上限 100,000；
- 输出 `DiffLineKind.Equal/Added/Removed/Changed`；
- 超限时显示“文件过大，无法在窗口内计算差异”，不阻塞主窗口；
- 差异窗口只读，不提供保存动作。

重新加载复用 `ApplyExternalRefresh`，保留现有锚点映射和取消检查。

### 4. Markdown 层次和性能

- `RenderedReading.StyleBlock` 继续作为统一样式入口；
- `MarkdownPreview.BuildBlocks` 增加代码语言标签、任务列表视觉状态和块级间距；
- 代码块复制按钮调用现有 `ReadingClipboard.CreateCurrentCodeBlockData`；
- 图片和 Mermaid 控件继续使用预算，不因窗口尺寸改变重新读取源文件；
- `MarkdownPreview.UpdatePresentation` 只重新布局现有 FlowDocument；
- 异步构建每批处理有限块数，并在 UI 线程让出调度权；
- 预览更新通过 generation 和文本快照确认，旧构建不能覆盖新文本。

## 错误处理与安全边界

- 搜索正则继续使用 350ms 超时和 10 万匹配上限；
- 差异计算超过字符/行上限立即降级，不分配无限矩阵；
- 外部文件读取失败保留当前内容；
- 预览构建失败保留编辑原文并显示状态；
- 当前文件切换、窗口关闭、退出流程会取消搜索、预览和差异任务；
- 目录、高亮和差异都不写入用户文件。

## 验收标准

1. Markdown 打开即全宽预览，编辑/预览来回切换内容、滚动位置和选择不丢失。
2. 目录层级和当前章节跟随正确，跳转后可返回原位置。
3. 搜索结果全部高亮，当前项明显突出，普通/正则/全词模式计数正确。
4. 文件外部更新后，当前标签切换或窗口激活能展示最新版本；未保存内容不会被静默覆盖。
5. 查看差异在正常规模文件中可打开，超大文件快速提示并保持界面可用。
6. 50 万字符 Markdown、含大量图片的 Markdown 和窗口反复缩放不会卡死、跳回顶部或显示旧内容。
7. 标题、引用、任务列表、代码块、表格和 Mermaid 在预览与复制中保持层次。
8. Windows Release 构建无警告，Markdown、阅读、搜索、外部更新和 UI 回归全部通过。
