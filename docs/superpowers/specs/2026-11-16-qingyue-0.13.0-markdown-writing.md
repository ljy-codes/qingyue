# 轻阅 0.13.0 Markdown 编写

用户已批准按五步持续完成。目标是让 Markdown 列表在输入、预览和阅读时都能辨认层次，并提高本机写作效率。

## 约束

- Windows / .NET 10 / WPF；Core 不增加第三方依赖。
- 不增加云同步、账号或历史数据迁移。
- 保留原生编辑器的源码偏移、选区、中文输入和撤销；仅明确保存时修改原文件。
- 文件保存标准 Markdown，显示圆点不得替换为字面 `•`。
- 行首 `- ` 即时显示实心圆，子层为空心圆，再下层为方块；代码块内保留原样。
- Enter 续项；Tab / Shift+Tab 改层级；空项 Enter 退一级或退出列表；Shift+Enter 插入项内换行。
- 有序项续号；任务项可以切换；多项缩进携带子项。
- 选区、代理对、CRLF、撤销、中文组词期间的按键都需保护。
- 标题、引用、粗体、链接、代码块提供快捷操作，工具栏显示当前状态。
- 分屏编辑与预览可以相互定位，避免过时预览和反馈循环。
- 预览、阅读和富文本复制保留真正的嵌套列表结构。

## 实施边界

复用 TextBox 输入与语法绘制层，不在本轮引入浏览器内核或替换整个文档编辑器。编写命令在纯文本转换层生成最小替换，在 WPF 层作为单个撤销事务应用。列表渲染使用真实的嵌套 WPF List / ListItem。
