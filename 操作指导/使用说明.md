# 轻阅 · Mac 使用说明

产品版本保持 **0.1.0**，本轮 **Mac 构建 5**，功能对齐基线为 Windows 0.3.0。目标为 Intel Mac、macOS 13+。采用原生 AppKit、系统文本排版、图像解码与剪贴板，不携带 WebView 或第三方运行时。

本轮逐项执行结果见 [Mac 构建 5 功能对齐](../docs/Mac构建5功能对齐.md)。Windows 与 Mac 的代码、安装包、快捷键和验收分别维护，不能把 Windows 的图文粘贴结果直接视为 Mac 已兼容。

## 打开、标签与保存

双击应用启动，使用“打开”或 `⌘O` 选择文件，也可拖入编辑区或传入命令行路径。Markdown 首次打开默认进入全宽阅读预览；点击“编辑原文”修改源码，再点“返回预览”继续阅读。明确恢复的会话按其记录模式打开。

打开操作显示读取、解析或排版阶段与已用时间，并提供取消入口；取消后不把该结果加入标签。不同处理阶段的取消粒度可能不同，不代表系统能中断每次底层磁盘调用。

- `⌘N` 新建；标签栏空白处双击也可新建，按“新文件 1、2、3”递增命名并避开重复。
- `⌘S` 保存，`⌘⇧S` 另存为，`⌘⌥S` 保存全部。
- `⌘W` 关闭当前标签，`⌘⇧W` 关闭全部；未保存内容逐份处理，取消或失败会停止后续操作。
- `⌘⇧[` / `⌘⇧]` 切换标签，`⌘1`–`⌘8` 选对应标签，`⌘9` 到最后标签。
- 标签支持拖动排序和右键左右移动；每标签保留独立撤销、正文和阅读状态。
- 双击标签或右键“重命名”改名。已保存文件修改同目录磁盘文件名，不自动保存当前脏正文；新文档只记录建议名，首次保存再选位置。同名目标不覆盖。

窗口内“文件、编辑、搜索、视图、标签、帮助”菜单与系统菜单提供对应命令。顶部侧栏开关收起后仍可展开；窗口记忆大小和位置。红叉关闭文档窗口，应用仍可在 Dock 中重新打开；`⌘Q` 退出应用。手动关闭标签或窗口移除相应会话项，退出可按草稿策略保留未保存内容。

## Markdown 阅读与分屏

正文支持标题层次、强调、引用、列表、任务、分隔线、行内代码、代码块和真实表格。它是轻量原生实现，尚非完整 CommonMark/GFM；不执行 HTML 或脚本。

点击“MD分屏”或“视图 → Markdown 分屏预览”可同时编辑与阅读，拖动中间分隔线调整两边宽度；点击关闭分屏回到完整编辑区。编辑后会防抖更新预览，未改变的内容尽量复用既有呈现。分屏编辑后立即复制全文，会先同步最新正文。

TXT/Markdown 使用正文阅读字体、行距和版心；JSON、YAML、INI 等结构化文本保持等宽缩进与高亮，查看不会自动改写文件。设置可调整字号、行号、折行、正文宽度和系统外观跟随；自动折行只改变显示，不改变磁盘换行。

`⌘⇧F` 进入专注布局，隐藏多数工具栏与侧栏。Esc 在查找打开时先关查找，否则可退出专注。系统全屏与专注布局是两项独立操作。

### 目录与返回位置

侧栏可切换“目录 / 最近”，目录根据当前 Markdown 标题或可识别的 TXT 章节生成。点击章节跳转，阅读时突出显示对应章节。`⌘⇧O` 也可打开文档目录。

“返回位置”或 `⌥←` 返回目录跳转前的位置；结束阅读查找可返回查找前视口。位置记录实际可见内容的源文锚点，而不只保存滚动像素。字号、版心和窗口宽度改变时会按锚点尝试保持阅读段落。

对应关系以块级为主：同一段、标题、代码或表格之间通常可以互相定位，但不承诺任意字符选区精确互转。外部大幅改写文档后，原偏移也可能不再指向相同文字。

## 图片、宽表和离线图表

### 本地与内嵌图片

Markdown 支持本地相对路径、绝对路径、URL 编码路径和 `data:image/png;base64,...`。中文、空格图片路径按本地文件处理；相对路径以 Markdown 所在目录为基准。未保存文档若使用相对路径，应先保存到正确目录。

图片异步解码并按正文宽度等比缩放。网络 URL、网络盘及非普通文件不自动读取；缺失、损坏、拒绝或超限会保留说明。当前预算：每篇最多 32 张，单图输入 8 MiB、合计输入 32 MiB、单图 1600 万像素、合计 4800 万像素，并使用受限的解码呈现。

点击图片打开查看窗口，提供适应窗口、解码尺寸、放大、缩小和复制位图；`Ctrl` 或 `⌘` 加滚轮缩放，Esc 关闭。已解码的安全呈现不一定等于原始压缩文件或原始分辨率；复制的是已加载位图。

### 表格

表格使用原生 `NSTextTable`，支持分隔冒号指定左中右对齐、转义竖线、代码内竖线及短横分隔线。单元格保留强调和代码样式；超出表格预算的内容保留源码。当前最多 32 列、1024 单元格。

在表格内右键可复制当前表格，或“展开表格（横向滚动）”在独立窗口阅读宽表。复杂嵌套表格和完整浏览器 CSS 不在当前范围。

### Mermaid 时序图

`mermaid` 围栏中的 `sequenceDiagram` 使用原生离线绘制，不执行网页脚本。支持 `participant`、`actor`、`as` 别名、隐式角色、消息箭头、自调用、Note 与自动编号。`<br>` 可换行；其他 HTML 按文字处理。

这是有限时序图支持：流程图、`alt`、`loop`、激活、配置指令和多语句分号写法暂不渲染。失败或超限保留完整源码并提示原因，不会忽略不认识的语句后继续绘制。

每图最多 32,000 UTF-16 单元、1,000 行、20 角色、200 事件和单标签 2,000 单元；整篇最多 12 图、64,000 源码单元、400 事件，绘制另有像素/面积预算。宽图可通过查看窗口横向阅读；图形不作为独立图片导出承诺，代码仍可查看、查找和复制。

## 复制与分享

| 入口 | 内容 |
| --- | --- |
| 阅读选区后 `⌘C` | 只复制选区图文，提供 HTML、原生富文本及纯文本格式 |
| 复制全文（含图片） | 全文阅读内容、真实表格和已加载图片，无需全选 |
| 复制全文纯文本 | 阅读文字，不携带富文本样式 |
| 复制 Markdown 源文 | 原文及 Markdown 标记 |
| 复制当前代码块 | 在代码块内右键操作 |
| 复制当前表格 | 在表格内右键操作 |
| 文件 → 导出自包含 HTML（含图片） | 将正文、表格和已加载图片内嵌为单一 UTF-8 HTML |

源码编辑区的 `⌘C` 仍复制源码；搜索框继续使用原生复制。复制全文不改原文或当前选区。接收方选择使用哪些剪贴板格式，排版、图片和字体效果取决于目标应用；不能承诺所有软件完全一致。

全文图文复制和 HTML 导出会有界等待图片准备，最多约 5 秒，并可取消；缺图、超限或未完成会提示后继续当前内容或取消重试。HTML 输出最多 20 MiB，图片内嵌 PNG，不必额外打包本地图片目录。不要用导出覆盖原始 Markdown 文件。

## 搜索、格式化与结构

`⌘F` 打开查找，普通、大小写、全词和正则均支持。阅读搜索搜索显示文字，输入后定位并突出匹配，继续输入保持搜索框焦点；上下一个切换匹配。Esc 关闭查找。替换修改源文，阅读时需回到源码编辑再执行。

正则替换可用 `$1` 捕获组；字面搜索中的 `$` 和反斜线保持字面含义。搜索最多 500 万 UTF-16 单元、10 万处匹配；复杂正则有可中止预算，不代表所有设备固定在同一毫秒内结束。大量替换先确认，全部替换可以一次撤销。`⌘L` 跳源文行。

顶部“格式化 / 整理文本”或 `⌘⌥F` 根据类型整理：

| 类型 | 处理 |
| --- | --- |
| TXT | 清理行尾空白、多余空行与前导 Tab，保留行内空格和正文分段 |
| Markdown | 保守整理独立标题/列表与空行，保护代码、表格、frontmatter、HTML 和两个空格硬换行 |
| JSON | 检查并排版，保留字段顺序、重复字段、大数、指数与字符串原始写法 |
| JSONC | 支持注释与尾逗号，保留原词法，注释位置可能调整 |
| XML | 保守缩进，禁止 DTD 与外部实体；保留混合正文、CDATA 和 xml:space 内容 |
| 其他已识别类型 | 仅整理行尾空白，先展示前后对比供确认 |

格式化上限 500,000 个 UTF-16 单元，有取消入口；结果落回编辑区前检查原文是否仍是本次快照。`⌘Z` 可撤销，`⌘S` 才写磁盘。没有完整语法支持的类型不显示完整校验已通过。

“JSON结构”打开原生只读树，可折叠/展开对象与数组，保留重复字段和数字原始写法，不改原文。支持 JSONC；上限 200 万单元、10,000 节点、128 层。

基础 TXT/MD/JSON/JSONC/YAML/INI/XML 外，还可识别 JavaScript、TypeScript、Python、Java、C#、SQL、HTML、CSS、Go、Rust、Shell、PowerShell、TOML 与 CSV。识别不等于完整着色或专用格式化器；YAML 仍仅检查缩进 Tab。

行号旁橙色为尚未保存修改，绿色为本次打开以来已保存的修改。草稿写入不把橙色变成绿色。装饰有独立预算，超过 200 万 UTF-16 单元或 10 万行会暂停标记；大量重复行的差异可能较保守，不影响文件修改状态。

## 会话、草稿与外部变化

- 默认明确保存原文件，草稿不随输入覆盖原文。
- 激活窗口或切标签会检查磁盘变化；干净文档可自动读取最新磁盘内容，脏文档保留当前编辑并提示冲突；删除或暂不可读仍保留正文。
- 保存时再次检查冲突，可明确覆盖、另存或取消。编码、BOM、换行与权限保持策略继续保留；混合换行修改后需明确统一。
- 会话保存标签顺序、活动标签、模式和内容位置；干净文件重启读盘，未保存正文单独恢复。
- 草稿约 1.5 秒防抖后后台串行写入，可全局关闭、按文件排除和清理；停止会话恢复不应因此丢掉仍被允许恢复的草稿。
- `⌘Q` 可按策略保存、保留草稿、放弃或取消；退出等待写入期间不应接收遗漏于最终快照的新修改。
- 损坏草稿会提示并隔离；同路径的多个未保存版本需作为恢复副本处理，而不是静默覆盖原文。

数据位于本机 `~/Library/Application Support/LightReader`。草稿是当前账户私有的明文，不是加密备份服务。异常退出只能恢复最近成功落盘内容，最后未落盘输入不保证恢复。

## 当前交付边界

单文件最多 50 MiB，Markdown 富预览正文最多 500,000 UTF-16 单元；源码高亮、格式化、结构、图片、图表和搜索各有独立预算。完整 Markdown、完整 YAML 校验、多窗口、文件夹全局搜索、超大日志专项支持、Office 编辑、云同步、插件和自动更新尚未实现。

当前是 Intel macOS 13+、ad-hoc 本机签名，未做 Developer ID 公证；Apple Silicon 尚未实机验收。Windows 客户端、安装器和资料目录独立维护。Mac 图标使用 Windows 同一份蓝青书页源图生成 ICNS。

构建 5 使用独立预发布 `macos-build-5`，历史包保留。更新前应处理未保存内容并退出旧进程，替换 `/Applications/轻阅.app` 后在“关于”确认 0.1.0 / Mac 构建 5。
