# Windows 构建 3：Markdown 时序图

日期：2026-11-09。产品版本 0.2.0，Windows 构建 3，文件版本 0.2.0.3。
基于 `feat/windows-client` 的 `bbadd2a`，本轮只修改 Windows 预览及相关测试、说明。

## 已确认事实

- 用户文档中的 `mermaid` 围栏包含 `sequenceDiagram`，原实现将所有围栏作为普通代码显示。
- 复制后的标题、表格、围栏仍是 Markdown 原文；未命名文档的既有自动识别能识别标题和围栏。
- `ReadingModel` 原先未保留围栏语言，显示层没有区分 Mermaid 的依据。
- 新增真实预览回归在修改前失败：12/13，通过的 12 项是既有 Markdown 检查；
  失败项明确为缺少真实图表控件。

## 当前方案及影响

保留围栏语言作为只读模型元数据。独立 Core 解析器处理有限的 `sequenceDiagram`
语法，WPF 原生控件绘制参与者、生命线、消息箭头和说明。完全离线，不引入浏览器运行时。
MD 分屏用图表替换代码块，源码可展开选择复制；阅读模式显示图表与原始代码，
以保留查找、目录和源文位置映射。预览不修改文件正文或编码。

支持范围以实际测试和使用说明为准；未知指令、语法错误与超限输入应显示原因并保留源码，
不允许静默丢弃消息。普通代码块、HTML、远程图片的现有行为保持。

修改链路：`ReadingModel` → `MermaidSequence` → `MermaidSequenceView` →
`MarkdownPreview` / `RenderedReading`。会话、草稿和语言枚举不迁移；无数据库、缓存、MQ或服务调用。

风险边界：这是轻量 Mermaid 时序图实现，不能宣称完整 Mermaid；
不支持的图类型或指令保留代码并显示提示。其他系统、DPI、辅助技术验收不在本轮既有证据内。

语法复核依据为 Mermaid 官方 `packages/mermaid/src/diagrams/sequence/parser/sequenceDiagram.jison`
及 `syntax/sequenceDiagram` 文档：`TXT` 消息与别名 `LINE` 保留 `%%`，
普通状态将其作为注释，ASCII 分号是语句分隔符。本实现限制每行一条语句，
不解码实体；无法支持的分号写法整图回退。相关回归包含正文标记、别名、Note、
头部/编号行注释以及先有有效消息再遇到非法语句的情况，防止返回部分成功图。
